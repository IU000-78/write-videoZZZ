# 输出格式与短例

先按[统一任务分流与阶段规则](question-flow.md)确定本轮交付；本页只提供已获放行的成稿写法，不另设问答门槛。纯审核按[事实与意图审核](intent-review.md)先报告确定问题，局部修改只处理请求范围；新创作不能借模板抢先出稿。默认镜号不加秒数，不主动询问是否标注，仅用户明确要求逐镜时长时添加。

需要创作的部分执行[导演发散设计](director-design.md)，将选定的视觉重心、情绪推进、表演细节与运动动机落实进各镜，不能只把剧本每句改写成长句；其他内部创意比较不默认全部展示，“只改X”等当前限制仍优先。

运镜选择阶段只输出一组A/B/C：每项含通俗名称、起始构图到结束构图的运动与焦点、适配本段的效果及主要取舍；可标一项推荐，允许自定义或看过方案后委托选择。等待回复后只写最终选定的运镜，不将3种互斥方案一起塞进生成正文。

连续近景、特写或正反打接行动时，按[特写密度与中景过渡](shot-transitions.md)决定是否换为主体中景；正文实际写出动作承接、留出的行动空间、对焦主体和背景柔焦，不能只写“加一个过渡镜头”。

多人或跨镜动作先按[防穿帮流程](continuity-workflow.md)内部核对人物清单、空间和起末状态。正文在关键动作处写明实际结束状态，下一镜接着发生；状态表只在用户要求制作稿或核对表时展示，不给每镜附加无关字段。

每镜自动按[场景可见范围与变化继承](scene-visibility-state.md)核对实际背景、明确禁入项和事件后的新状态。公共设定写全段限制，相关镜号用简短背景说明落实；墙面损伤、门窗、灯光或陈设改变后，完整稿同步更新所有后续涉及区域，不将无关场景清单逐镜粘贴。

按[故事构图](composition-story.md)将必须看清的细节分配到合适镜号，写明可见侧面、构图位置及焦点，不用“始终保留”替代。台词只将实际发声原句绑定口型，中文释义不重复读、不转成字幕；OS/VO与画内对白分开。

涉及特效时自动按[特效来源与阶段](effects-continuity.md)把必要内容写入对应动作：从哪个部位开始、按什么进度发展、何时持续或消散，以及适用的同步音效。状态资产先分清同一物件的不同阶段，切镜接续进度；不在无特效片段新增效果，不将通用检查清单逐镜粘贴。

真人正式提示词按[真人结尾模板](style-profiles.md)在正文末尾自动追加一次精简的质感与连续性约束；含指定摄影机运动时把公共摄影要求合并进去，不重复尾注。其他风格含摄影机运动时，按[主文件的默认摄影尾注规则](../SKILL.md)追加一次公共摄影要求。尾注不新增或替换已指定运镜；明确的其他拍法与局部修改范围优先。纯固定片段不追加运动句，不将人物动作、转焦或剪辑当成机位运动。

内部场景坐标与俯视图沿用固定八方位，罗盘仍标N、NE、E、SE、S、SW、W、NW。正文场景朝向及移动在字母后加“方位/方向”，如“向N方位迈出一步”；人物相对位置用参照人物自身的前后左右，不写“某人的SE方向”。先确认身体朝向再换算，分开位置、面朝与移动；屏幕左右和景深按实际镜头判断，反打不镜像世界坐标。

配图先执行[按需门槛](blocking-camera-diagrams.md)：仅本段确需中景/全景交代人物关系、走位或交互时提供站位图；纯近景/特写及其反打不配，即使多人真实在场。每个适用段落默认一张，先复用有效图，不自动追加关键构图、阶段图或起落幅；白模仅实际特效需要且用户同意后制作，不因复杂站位或旧白模自行升级。

段首集中一次写“空间锁定”：实际@图、必要人物与C/S/P映射、固定锚点、起始位置/朝向及关键道具状态；只写本段有用的信息。后续镜号不重复公共站位和图例，仅写摄影、动作及改变后的状态。单镜/长镜需要图时用A/B/C俯视素描，长镜不画摄影机轨迹、正文不用途经机位序列；其他多镜图沿用人物数字与C/S/P。无图就省掉图片和标记词典，仍在内部检查空间与连续性。

获准白模只绑定实际生成图片的用途和适用动作，不默认“总图＋每镜一张”；各图从同一空间推导，真人外观和光影沿用已确认资产。已用图片须核对实际文件、视觉内容及正文引用，不能把图文自洽说成模型执行保证。

## 完整视频提示词

使用一个可复制、无空白间隔行的文本代码块承载正文；按内容保留必要的公共设定和镜头，输出时替换全部占位内容。普通完整稿采用以下结构，不强制机械填满每个标签：

画幅与帧率不作为模板必填字段；遵守主文件的参数省略约定，默认省略9:16竖屏与24fps及等义写法，保留既有构图要求，不以另一种说法补回这些参数。

镜号默认用“镜号1：……”，不附秒数，也不主动提供时长标注选项。只有用户明确要求逐镜秒数时才用“镜号1（4秒）：……”。该数字只是格式示例，须按实际对白、动作与运镜分配；存在指定总长时核对总和。时长不是每镜模板必填字段。

```text
整体设定：题材、风格、时间天气、设备成像与运动质感。
人物与资产：@人物及本段必须锁定的身份、服饰、持物和@场景。
空间锁定（仅在对应段首一次）：必要@参考图及映射、固定锚点、人物起始位置/朝向、关键道具状态与主光方向；无图不造引用。
镜号1：（景别与叙事任务）
设备与焦段；机位、角度、焦点；摄影机起点、路径和终点；人物动作与表情、准确对白；本镜结束状态。
镜号2：（与上一镜连续的下一任务）
设备与焦段；景别与构图；接续的动作及受力/反应；焦点、对白与结束状态。
声音与连续性：与动作同步的环境声、拟音、对白与必要的全段约束。
结尾约束：（真人画面按风格规范合并一次质感、连续性与适用摄影要求；其他风格仅在含摄影机运动时按主文件追加摄影尾注，不输出此占位说明。）
```

若用户只要某一镜，只给该镜可用的必要设定与镜头内容；保留指定编号，不重编号全剧。若用户只要一镜到底，使用一个镜号，以起始、经过、结束描述运动；仅满足中景/全景及空间需要时配一张A/B/C俯视素描，摄影机路线用自然语言写进正文，不插入剪辑或伪装成连续的多机位切换。

关键状态可紧凑写成：“松手完成后，@甲右手已与@乙左腕分离；@乙收回左腕，用右手护住，二人仍在门外同一平台；下一镜从这一姿态继续。”按实际场景替换，不能把此例的角色、手别或地点当作所有项目默认值。

## 特写与局部近景简写

采用[特写正文顺序与mm要求](closeup-prompts.md)：已有草图时只在段首一句@草图交代方位，后续不重复，再写数值+mm、必要机位、入画部位、谁做动作、物体如何运动和停住、谁从哪边出画。直接以实际@资产绑定可见执行者与物件，不展开整图标记词典或画外名册；没有移动或出画就不增添，用户单独要图例时再另给说明。

简写保留焦段、接触次数、左右手脚、必要状态及锁定对白与剧情。完整真人稿仍合并一次适用的质感与摄影约束。

## 克制表演短例

```text
镜号1：上半身近景，察觉门外动静。
ARRI Alexa 35，Cooke Panchro 50mm，摄影机在@成年旅人的左前方停稳，人物占画面中右侧，后方门洞虚化。@成年旅人听见门外一次脚步停顿，目光先移向画面左侧门口，下颌轻收，吸气短暂变浅，然后缓慢转头；双眼随目标自然转动，神情从专注转为警觉。摄影机保留几乎不可察觉的微呼吸感。结束时人物仍在原位，身体没有突然转向门口。仅有室内风声、衣料声和门外脚步，无配乐、无字幕。
```

此例示范目光、呼吸和动作顺序，不能把它的人物、场景、焦段或情绪复制到不相关任务。

## 定向修改

- 用户要求只修改一个角色、表情或镜头时，把原文中对应片段替换，其余原文保持不变；只有可说明的依赖冲突才联动修改。
- 修改后默认返回当前片段或稿件的最新完整提示词，不只给替换段；只有本次明确只要修改段、单句或差异时才局部交付。完整交付不扩大修改权限，其他原文保持，仅同步必要依赖与已确认的时长。
- 用户给出明确保留项时，将它们当作检查项，不要借优化删除原有物品、角色、台词或动作。
- 当目标是修改已生成的视频时，描述最终画面应如何呈现与保持哪些已确认关系，不使用“参考原视频”“参考原图”等泛指句。
- 不把“同上”“按原设定”“其余不变”当作完整稿的主要内容；把执行所需的原设定实际写入，除非用户明确只要修改指令。

## 以画面作为起点

- 先查看实际附图，记录画幅、人物站位、面朝方向、持物、背景锚点及光线；区分真实可见细节和推断。
- 让动作从首帧中的姿态和位置开始，不先换场、换服装或重置人物方向。
- 用户明确要求锁定首帧时，使起始构图逐项对齐；没有明确锁定要求时，保留关键视觉关系并按剧情组织运镜。
- 把参考关系转写成明确的@资产、空间和造型描述，不在最终提示词里反复写“参考原图”。
- 无法查看附件且任务依赖其具体站位时，说明缺少哪项可见信息并请求该素材；不捏造观察结果。
