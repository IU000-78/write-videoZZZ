# 分镜、表演与配图：制作行为回归任务

用于更新技能后的按需试用，不是每次创作都向用户输出的问卷。工具确定性测试见[脚本](../scripts/test_blocking.py)，出图规范见[站位与机位图](blocking-camera-diagrams.md)。本页不证明任何视频模型已执行成功。

## 执行方法

- 每次只选与改动相关的少量任务，使用独立上下文，提供当前技能与下表的“原始任务”；不要把“观察项”、预期修复或历史结论发给执行者。
- 实际检查回应和产物；图片任务必须查看PNG，按分支确认单镜A/B/C或普通多镜人物数字、C机位及已有场景资产S标记分明，核对正文中的引用名、人物序号映射、固定锚点、朝向及路线。普通关系段的必要站位说明只在该段开头进入提示词代码块；特写按简写例外保留必要引用与可见动作，不以展开所有标记为通过条件。记录通过、失败、未覆盖，不把只说“会画图”算作完成，不因工具测试通过便推断AI行为通过。
- 下表均为可迁移的合成任务，不是用户项目默认人物、参数或场景。

## 白模门槛与判定边界

| 原始任务 | 维护者观察项 |
|---|---|
| “只说明、不出图：三人在厅内争执，依次拍全景、单人近景和抓臂特写，没有超自然效果。已有旧白模，下一次该怎么配图？” | 中景/全景确需空间关系时至多一张必要站位图；近景与抓臂特写不另配，旧白模不触发继续生成；无特效不询问白模，不恢复总图加每镜构图包。 |
| “只审核不改稿、不出图：三人在石厅，甲推乙后停在乙自身右后侧，丙在对面。俯视图只有圆柱数字，丙的反打也复制了原大厅背景。成片看起来甲乙并排，一定是编号图造成的吗？” | 核对人体朝向和实际背景，区分二维投影与真实换位；不无证据定因，不因穿帮直接推荐升级白模；没有特效不触发白模。 |

引用检查不能验证真实遮挡、可达高度、复杂路线或视频执行；独立试用不发送消息、不发布内容、不调用收费视频生成。额外图仅限任务明确要求或现行门槛，不能用检查为由扩成整套出图。
