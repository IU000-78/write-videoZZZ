# 导演发散、视觉吸引力与观众情绪设计

将剧本当作核心事件与表达意图的依据，主动完成从文字到视听的再创作。目标是让观众愿意注意这个画面、期待变化，并在适当位置感受到情绪或信息的兑现。本文流程与例子为自行综合的导演方法，参考依据见[研究与创作资料](director-sources.md)，不是保证播放量或通用情绪效果的公式。

## 一、默认创作权限

- 默认可以重构未锁定的观看角度、镜头顺序、景别、运动路线、构图、表演细节、反应与停顿。可以把一个剧本动作拆成准备、过程、结果，也可以用一个有层次的连续镜头合并重复覆盖。
- 默认保留核心事件、人物身份与关系、既定台词、场景世界、前后因果、故事结果及明确的必须保留项。保留的是表达目的与故事骨架，不要求每句舞台说明等长照拍。
- 有因果的小动作、环境互动、反应和声音细节可以主动补充，例如欲言又止、脚步放缓、触碰既有物件、由先前事件引发的群体安静。不得把不存在的动作说成原稿已写，也不要凭空创造角色动机或支线。
- “只改表情”“其他禁止改变”“严格按这些镜头”“一镜到底”“不出现其他人物”等当前具体要求优先。发散在允许修改的范围内完成，不重新申请已经给出的许可，也不借自由发挥改掉明确限制。
- 主要情节、人物动机或结局的改动与普通视觉重构分开。用户已经授权剧情改编时按范围执行；否则将这类改变作为明确标出的改编方向，只有决定性意图不明时才并入最多三个问题，不把它悄悄混入最终稿。
- 何时问意图、何时选择运镜，统一按[任务分流与阶段规则](question-flow.md)执行。本页只在允许创作的范围内设计，不把纯审核和局部替换强制转成新创作问卷，也不要求重复授权。

## 二、每段先建立观看任务

在内部用简短语言明确以下内容，不默认让使用者填写表格：

1. 这一段正在发生的关键变化是什么？角色在争取、躲避或失去什么？
2. 观众首先应该注意谁、哪个动作或哪条关系？为什么愿意继续看？
3. 此刻观众比角色多知道、少知道，还是同时知道？什么线索必须露出，什么内容应延迟？
4. 观众的感受从什么状态走向什么状态？转折发生在何种可见动作或反应中？
5. 这段结束时兑现了什么，又将哪项期待自然交给下一段？

涉及发现、隐瞒或躲藏时，按[叙事前提与角色察觉](narrative-conditions.md)先检查事件成立条件，逐人区分知情状态与真实视听条件，再发散机位、调度和揭示顺序。观众信息、各角色信息与画框不是同一层；主动设计不能破坏已确认的未被发现、禁同框、进门顺序或故意曝光结果。

不要把“每段都有观看任务”变成强加爆点、反转或悬崖结尾。过渡、喘息、安静观察和关系建立同样可以有明确作用。

## 三、先发散，再收敛成一种可执行方案

内部提出2–3种真正不同的视觉组织，至少从观看位置、信息顺序、人物调度、节奏或声音中的一项改变思路。仅将35mm换成50mm、给同一方案堆形容词，不算不同设计。

例如可比较：

- 跟随角色逐步发现，让观众与角色一起理解。
- 先露出一条角色尚未察觉的线索，让观众等待其反应。
- 将注意力放在克制的反应、手部或人物距离上，延后直接展示结果。

这些只是候选思路。根据当前意图、可读性、画面美感、情绪变化、素材约束与生成复杂度筛选，不能只按运动幅度选。需要向用户选择的运动按[统一流程](question-flow.md)办理，其他创意比较留在内部。每个候选先通过锁定条件与场景可行性检查；完整提示词只包含最终选定方案，不混入互斥备选。

选定后说明具体因果：哪种构图或调度令观众先注意什么，什么动作改变预期，摄影机为何在此时移动或停住。把有用的新设计直接落进提示词，避免只在解释里说“我会更有导演感”。

## 四、组织情绪变化与信息兑现

优先建立“可读的状态→变化线索→预期或犹豫→关键行动/揭示→反应与余韵”。按需要删减或重排，不为每段机械凑齐阶段。

| 目标体验 | 可探索的视觉组织 | 判断重点 |
|---|---|---|
| 好奇、悬念 | 先给有意义的局部、目光或画外声，让观众形成问题，再逐步提供依据 | 有线索和后续兑现；隐藏不能导致完全看不懂 |
| 压迫、权力变化 | 利用高度、距离、前景占据、进退与停顿，随关系变化重构画面 | 角色真实位置可读，避免全段同等强度 |
| 温暖、共情 | 让角色保留选择与犹豫，通过接近、回避、再接受的小变化形成情感 | 关注行为与回应，不自动加哭泣或煽情配乐 |
| 动作冲击 | 先建立目标与可接触距离，让一次命中有准备、接触、受力和结果 | 关键接触清楚，反应有重量，避免切掉全部因果 |
| 壮阔、惊叹 | 先给尺度锚点，再有层次地揭示空间或变化，留出看清结果的构图 | 场面大小有参照，不把角色自动摆成英雄姿态 |
| 喜感、意外 | 建立合理预期，通过延迟、画面关系或结果差异制造落差，给反应留余地 | 笑点来自情境，不靠强制鬼脸或新增胡闹剧情 |
| 苦涩、失落 | 通过已建立的日常动作、缺席、未完成动作和克制停顿表现变化 | 需要既有故事依据，不凭空添加悲剧或回忆 |

情绪变化不必等于强度持续增加。紧张后的短暂放松、动作后的静止、说完话后仍停留的反应，都可改变观看节奏。切镜不必追着每句台词走，优先判断观众此刻需要听话者、说话者、动作结果还是画外信息。

## 五、让画面精美且有明确重心

具体构图执行[故事构图与可见性检查](composition-story.md)：先确定必须读出的关系，区分状态持续、本镜必须看清和延迟信息，再核对实际机位、取景范围、焦点、遮挡与首末态。不能只在说明里声称细节存在，正文却将它裁掉或糊掉。

- 每镜建立主要视觉重心，明确观众首先应看到的眼睛、手、物件或人物关系；用亮度、清晰度、位置和遮挡引导注意，避免所有元素同时抢眼。
- 设计真实的前中后景、负空间、门框/柱廊等现有锚点，以及人物之间的形状关系。前景遮挡应参与揭示或空间层次，不为装饰挡住关键表演。
- 用人物距离、站坐高度、进退、转身与面向表达关系变化。可以让演员调度改变构图，不必每次都让摄影机绕行。
- 保持既定主光、天气、材质和色彩关系。通过方向、局部明暗、背景分离与有限色彩呼应增加层次；不因追求唯美就统一磨皮、全身打亮、增加不合场景的光束或重置夜景。
- 相邻镜头的视觉重心应有可读交接。方向、视线、图形或动势可以连接画面；使用反差时明确观众应如何重新找到目标。
- 特写用于身份揭示、信息变化或重要反应；安静的中景、双人关系景和能读懂动作的较宽景别同样可以成为视觉亮点。不要默认每镜大特写或强行把所有人挤进近景。
- 原稿物件与素材有限时，优先重新组织现有元素。新增布景或道具必须合乎场景且有叙事用途，不以添加奢华装饰代替导演设计。

## 六、让运镜和剪辑有动机

先写观众体验，再从[镜头选择库](camera-library.md)选择技术。每次运动回答：被什么触发、改变哪层信息或人物关系、何时应停住。

| 具体动机 | 可用手段 | 必须写清 |
|---|---|---|
| 注意力由环境收向人物的一次决定 | 推进、人物靠近或构图收束 | 开始靠近的动作节点、焦点与结束景别 |
| 从局部结果读出更大的处境 | 后拉、升起或解除遮挡 | 最初隐藏的空间是什么，露出顺序与尺度 |
| 陪伴行动、保持即时感 | 跟拍、迎拍或连续长镜调度 | 路线可走通，主体转向与焦点交接连续 |
| 关系或权力发生改变 | 有限弧线、人物换位或重构双人景 | 谁移动、距离如何变化，视线与轴线如何保持 |
| 某条线索改变理解 | 转焦、切细节或转到反应 | 哪条线索被看见，信息与反应的先后依据 |
| 关键动作需要被看清 | 停稳、动作衔接切或延后切镜 | 唯一接触点、受力方向与下一镜起始状态 |
| 需要让观众等待或体会 | 固定构图、减速或保留余韵 | 画内有什么细微变化，等待最终对应什么结果 |

上述对应关系是可探索的设计，不是“推进一定紧张、环绕一定高级”的固定含义。保持一镜到底时用人物调度、焦点与构图变化组织节奏；硬切时选择信息、动作或反应节点；真正的固定镜头不为了好看强加运动。

运动路线采用“起始机位/景别→触发事件→连续路径或分阶段变化→焦点交接→结束构图”，保留当前项目的自然持机呼吸约定。镜内运动与剪辑、变焦与机位位移、转焦与物体移动分别描述，避免互相替代。

## 七、用声音与表演补充画面

- 优先使用有来源的脚步、呼吸、衣料、风、火与场景混响，声音可以先于画面引发注意，也可以在揭示后提供确认。
- 用相对安静、声源远近和已有声音停止形成对比，不能随意把所有环境声清空或夸张成每次动作都爆响。
- 保留对白、OS/VO与动物声音的原有身份。内心独白不改成喊话，动物不新增人类台词；对白内容不因吸引力而擅自重写。
- 观众感受、角色真实心理与外在表演可以不同。让具体行为留下理解空间，不用“观众必须感动”替代可见变化。
- 默认仍无BGM、无新增字幕，只有当前要求改变时才按新要求处理。

## 八、转成SD2.5可执行描述

- 在正文中落实主体、场景、起始姿态、可见微动作、摄影机路径、焦点、揭示顺序、切点、声音与结束状态。抽象目标可以指导内部设计，不能成为正文的全部。
- 每镜容纳适量任务；复杂复合运动按阶段描述，关键动作保持清晰。未提供视频参考时依然可以写具体方案，不以缺少参考为由停止正常创作，也不把复杂术语当作保证。
- 保留此前的参数省略要求：不默认写出9:16竖屏、24fps及等义表述；镜号默认不加秒数，不主动询问时长标注，只有用户明确要求逐镜秒数时才加入。新设计不撤销自然表演、@角色标记、真实比例与连续性规则。
- 根据请求范围输出。只要提示词就交付选定设计；审核任务可以用少量文字说明原稿为何平、怎样改善观看体验、承担何种取舍，再给改稿。不要让创作理论淹没可用正文。

## 九、出稿前的导演检查

1. 主要事件与作者核心想法是否保持，新增细节是否有动机？
2. 观众第一眼看哪里，接下来为何愿意等待，最终看到了什么变化？
3. 情绪是否有层次与转折，是否只反复描述同一种表情？
4. 构图、调度、光线、声音和运镜是否共同服务同一个重点？
5. 每次运动或切镜有没有信息/情绪动机，关键反应是否被过早切掉？
6. 视觉吸引力是否落实到可见设计，而不是“高级、震撼、精美”等空泛词？
7. 画面是否依然可生成、可读、连续，是否为了美观毁掉动作接触或作者要隐藏的信息？

效果是待通过作品检验的创作判断，不承诺观众一定喜欢或某类镜头必然提升完播。已有作品或用户反馈可用于针对性比较和调整，不捏造流量数据。
