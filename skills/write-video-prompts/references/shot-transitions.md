# 特写密度、主体中景与动作过渡

按使用者的观看目标安排景别与切点。对话中可用正反打呈现话语、倾听和反应；当任务转为起身、转身、靠近、交物或离开时，让能容纳行动的画面接住变化，给观众看清动作与关系的机会。以下是创作与审核规则，不承诺某种景别一定提升完播。

## 一、先判断是否真的需要过渡

联看相邻镜头，检查：

- 是否反复切相似的脸部表情，却没有新的信息、关系或情绪变化。
- 是否每句台词、每个词或每次眼神都机械换镜，尚未读清反应就离开画面。
- 是否从脸部直接切到人物已经离开、站起或走到别处，省掉了本应连续的行动准备与过程。
- 是否要拍转身、起身、走动等身体行动，原有特写却无法容纳手臂、躯干、动作方向及目的地关系。
- 是否连续局部画面令观众难以判断谁在何处、向哪里行动；声音、视线或既有锚点也不足以补清。

连续特写不自动等于节奏过快。压迫对话、刻意隐藏空间或需要完整保留的细微反应，可以继续使用或停留在特写。依据实际表达判断，不设“每几个特写必须加一个中景”的配额，也不虚构未提供的剪辑时长。

## 二、用行动改变景别

1. 找出由“说/听/反应”转为“决定并行动”的具体节点。需要读清最后反应时先保留它，在动作准备或动作衔接处切入中景，避免把关键反应过早截断。
2. 优先将附近一个重复或承载不足的特写改为行动中景；确有缺口才补镜。过渡画面应展示决定、身体转向、距离变化或离开过程，不为凑节奏硬插空景、黑场、叠化或其他转场特效。
3. 以行动角色为主体，写清取景范围与行动侧留白。中景可容纳腰部或大腿以上的转身、手部与部分行走；若必须看清全身、脚步接触或多人空间，再用中全景或必要的关系景，不要求中景同时显示全脸细节和完整远处路线。
4. 承接上一镜的台词末点、身体朝向、手部和重心。起身、转身、迈步只发生一次；可在动作中匹配切换，不从新机位重新开始整套动作。保持对话轴线、屏幕运动方向、既有光线及门口位置。
   用[逐镜状态核对](continuity-workflow.md)检查中景是否继承人物所在平台/台阶、相对距离、人数、接触对象和门扇状态；中景承担空间证明，不能只靠拉宽景别掩盖位置变化。
5. 写清主体从哪里开始、向哪里移动，摄影机固定、摇摄或跟随到哪里。中景保留到本镜的有意义动作阶段完成或出现新的信息节点，再按需要切到反应，不把连续行动拆成无依据的脸—脚—脸快切；仍不自动添加秒数。

## 三、主体清晰，其他元素自然柔焦

- 单一人物开始行动时，默认将注意力留给该人物。明确“焦点持续跟随@行动角色的眼睛/面部或上身”；运动中维持主体清晰，不让其走出焦平面后失焦。
- 将“其他都是虚影”转写为“其他人物与背景处于景深外，呈自然柔焦轮廓”。他们仍在原位置活动或倾听，具有真实体积和遮挡，不是半透明、重影、残像、磨糊全画面或直接消失。
- 保留门框、墙沿、路径方向等足够可辨认的轮廓，帮助观众理解去向；背景柔焦不能抹掉行动依据，也不要求单一浅景深同时把所有不同距离的物体都变成同样的模糊度。
- 如果他人的清晰反应或双人关系是必须保留的信息，按当前要求选择关系中景、适量景深或有动机的焦点交接；不要为突出行动者删掉既定反应。没有需要时，不在主体刚起步就抢切背景人物特写。
- 维持自然光、曝光与轻微摄影机呼吸。稳定机位不自动变成大幅跟拍，柔焦不依靠新增光效或烟雾实现。

## 四、遵守既有拍法和修改范围

- 一镜到底不新增镜号或隐藏切点：在动作准备时通过可走通的后移、摇摄或人物与机位配合，连续由近到中，跟随对焦并在同镜中完成行动。区分真实机位位移与变焦。
- 锁定固定机位时不擅自移动摄影机；可以在允许重设计的镜头中预留行动构图。若同时锁定整段特写、禁止改变景别或只允许改表情，保持限制；审核时可指出容量问题，不能自行插镜或拉远。
- 已有景别变化、空间可读且动作完整时，不重复添加过渡。主要意图、必要反应、台词与动作不因“降特写密度”被删改。
- 只有关键取舍仍不明确时，才将问题纳入本轮最多三个意图提问；已授权优化景别和切镜时直接实施，不逐镜再问许可。

## 五、对话结束后离场的写法示例

示例前提：上一镜中@甲已经说完原有台词，仍站在画面中左，@乙在其左后方，出口门洞位于右后方；此时允许调整景别，目标是把注意力留给@甲离开的决定与动作。实际项目应换成其真实角色、站位、路线与焦段。

```text
镜号3：对话结束，承接转身与离开。
ARRI Alexa 35，Cooke Panchro 50mm，固定中景，取景从头顶至大腿以上，摄影机保持对话轴线同侧，在画面右侧留出转身和走向出口的空间。承接上一镜，@甲仍在原处，话已说完，没有重复对白。他收回看向@乙的目光，肩部先向右后方转动，重心随转身移到支撑腿，随后迈步朝右后方门洞走去；转身和起步连续完成一次。焦点平顺跟随@甲，面部转离后保持其可见侧脸与上身清晰。@乙留在左后方，身体轮廓与后方环境自然柔焦，出口门框和行进方向仍可辨认，光源与人物位置不变。摄影机停稳并保留几乎不可察觉的微呼吸感，让@甲从原位置走向门口的这一段行动完整读出。衣料、脚步与室内环境声连续，无BGM、无新增字幕。
```

该例仅演示由对话转到主体行动的承接，不规定每段都离场、都用50mm或都固定拍摄；只有路线与构图允许时才这样安排。
