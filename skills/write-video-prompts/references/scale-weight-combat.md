# 体型差战斗：先立尺度，再显重量

依据用户提供的“先写它有多大／再写它有多重”两张画面要素图，归纳以下制作方法。用于已有剧情中大小对手的战斗、压制与反击；不代表已验证的模型控制参数。任务分流、意图提问、运镜选择与局部修改范围仍按[统一流程](question-flow.md)执行。

## 一、判断何时应用

- 在角色资产或剧情明确存在显著体型差时主动应用，包括较小人物对抗高大人形、巨兽或大型机械。普通同体型对话不触发。
- 先沿用已定身高、体型和道具比例；未给准确数字时用稳定的相对尺度，不擅自把“高大”改成数米巨人，也不要求用户填写无关参数。
- 保留已锁定的胜负、力量来源、人物身份、场景、同框限制、景别和摄影机运动。审片区分文本设计与实际执行，不承诺这些规则能保证成片无误。

## 二、让观众先看出大小

- 选择当前场景已有的参照：较小角色、门框、台阶或固定家具。用同一空间平面或清楚的纵深说明比例，避免只靠近大远小制造虚假的身高差。
- 在相关关系镜头中，可让大体型角色占据半幅或更多画面，肩背、躯干从边缘切入，较小人物保留可辨的头肩或身体。将占幅作为可选构图手段，不给所有镜头规定相同百分比。
- 拍法允许时采用低视点向上看，让大体型角色头肩接近画面上缘，保留较小人物或环境锚点。低机位不改变角色真实比例；当前指定平视、单人或固定景别时，改用允许的参照与遮挡。
- 手部、眼神特写可以暂时不展示双方；此前或之后的关系镜头应有足够的尺度依据。明确禁同框时不强行加入对手肩背、倒影或额外旁观者。

## 三、让重量通过环境和惯性出现

- 组织“重心压入支撑脚→脚掌实际接地或攻击接触→附近介质响应→受力者位移→余波衰减”的可读因果。并行动作用阶段匹配切镜，不重复落脚或命中。
- 按素材选择介质：已有薄尘可贴地散开，已有松动碎屑可轻弹，积水可产生涟漪；清洁完整的石地面可以只表现鞋底受压、衣料惯性和沉重接触声。不凭空增加沙地、碎石、裂缝或坍塌。
- 若剧情已有强力冲击或神力，按其来源与作用范围增强尘屑和环境响应；常规落脚不自动制造爆坑。声响对应真实接触点，摄影机保持已选稳定方式，不用全程震屏代替重量。
- 受击者的后撤、踉跄、飞退、撞墙、落地滑移按力量和空间选择。飞退不是每次击打的必选项；已经锁定飞退时，延续同一受力方向，落地后用摩擦、身体惯性完成停止。
- 落脚扬尘、碎屑轻弹可先于附近人物的后续反应出现，但必须已经有接地、撞击或明确的能量触发。不要把“余波先动”写成无原因的碎石提前起飞；墙屑应在墙体受撞后才松落。
- 让重体型角色的肩背、衣料或甲片响应起步与收势，保留动作速度与惯性的关系。体型大不自动等于全程迟钝，力量强也不自动抹去重心与支撑。

## 四、保证小体型反击能够到达

- 核对身高、臂展、武器长度、身体朝向和目标高度。不能让较小人物站在原地就无依据触及远高于自身的部位，也不通过镜头切换让大对手突然缩小。
- 先用当前动作建立可达条件，例如大对手俯身压制、屈膝追击或转身露出身后空间。环境借力必须使用场景已有支点，不凭空加入台阶、踏板或障碍。
- 只有剧情已给出跳跃、瞬移或临时赋力时才使用相应能力；交代起效、接近与结束，并延续原有伤势。不要为了制造对比擅自改写弱者获胜或强者压制的结果。

## 五、让快切兑现为一次动作

- 蓄力时可交替切眼神与手部；拔刀时可交替切目光与出鞘进度。每次切回都承接新的阶段，不重新抓握、拔刀、蓄力或落脚。
- 动作进入接触前，回到允许的关系构图，读清大小、距离、支撑和发力方向。当前锁定特写时用已建立的关系与匹配动作衔接，不强制新增全景。
- 关键接触稳定可读，随后才交接受力位移与余波。切近景不重置大对手的体型，尘雾和特效不遮断关键手部连接。

## 六、交付前检查

1. 大小参照来自实际人物或场景，身体与武器比例跨镜一致。
2. 占幅、低视点及局部遮挡服务于当前镜头，没有越过用户的拍法或同框限制。
3. 落脚、接触、尘屑、位移、墙屑与落地的先后有依据，环境破坏符合材质和力量。
4. 较小人物的反击高度与距离可达，临时能力和伤势保持连续。
5. 快切推进同一次动作，关键接触与结果有可读交接；没有为强调重量而重复命中或延长悬空。

在最终提示词中只写本镜需要的两三条可见细节，将完整检查留在内部，避免把整份规则重复塞进每镜。
