# 任务分流、制作意图与运镜选择

本文是本Skill关于任务分类、问答顺序、阶段放行、跨轮继承及按需秒数的唯一流程依据。其他参考资料提供摄影、审核与写法，不能扩大为“任何任务都必须先问”。历史修改日志只记录过去，不作为现行流程。

## 一、先分任务，再决定是否提问

| 当前任务 | 本轮先做什么 | 何时提问或选择运镜 |
|---|---|---|
| 新剧情、图生视频、新补镜、新段落续写、整段重新创作 | 提出1–3个本段制作意图问题并等待回答，不附初稿或运镜菜单 | 回答足够后检查运动是否已指定；未指定时进入3方案选择，选择后才出稿 |
| 只审核现有文字或已查看的视频 | 立即报告已有证据支持的矛盾、违背要求及成立条件，不强加改写 | 只有某条判断依赖未知意图时，就该条追问；其余确定结论照常给出。不要求先选新运镜 |
| 审核并改写 | 先报告确定问题，再按改写范围处理 | 最小技术修正走局部修改；重构新表达走创作问答。未解决的疑问不能阻止已成立问题的报告 |
| 只改一项门色、表情、称谓、衔接或已有镜号内容 | 沿用可用设定，只修改指定项及不可避免的依赖，默认整合返回当前稿全文 | 只有真实冲突影响结果时才补问；不补做新片段问卷，也不因旧稿未写运动而弹菜单 |
| 同一片段已回答意图，尚未指定运动 | 简短复述实际答案，给3个适配运镜并等待选择 | 不重新问意图，也不提前附成稿 |
| 同一片段意图与运动已确定，要求完整稿或继续修正 | 直接内部设计、检查并出所需稿件 | 不重复确认、重弹菜单或询问是否标秒 |
| 查询技能、解释术语、查看选项、技能维护、单纯改字或格式 | 直接完成请求 | 不触发创作问答 |

“继续”本身不等于新片段：若在回答上题、索要当前完整稿或修改当前镜头，继续当前阶段；有明确新剧情、新事件或新补镜时才开启新片段。换成另一段纯审核仍走审核分支，不能因素材新就改成创作问卷。

## 二、跨轮只更新受影响的状态

在内部保存必要的简短记录，不默认输出表格或要求用户填写：

| 字段 | 记录内容 |
|---|---|
| 当前范围 | 项目/片段、任务类型、原镜号、允许修改部分、必须保留部分 |
| 流程阶段 | 本段意图待回答/已回答、运动已指定/待选择/已选定、是否仅限本次豁免 |
| 表达与素材 | 用户实际说明的观看目标、信息顺序、角色/资产、台词、已读素材与未验证假设 |
| 当前约束 | 世界坐标、人数、动作与接触、场景状态、关键可见细节、角色察觉状态与真实视听条件、禁同框组合、发声语言、总长或逐镜标秒的明确请求 |
| 本次变化 | 最新更正、受影响镜号与依赖；仍有效的其他设定和下一步 |

- 最新明确纠正优先于旧稿，只替换相关字段并传递到依赖项。例如门从留缝改为完全闭合，同步取消该门缝光带，不顺手改台词、人数和镜头；整合完整稿时不能恢复旧门缝。
- 当前片段已明确的用词、资产标记和动作表达偏好一并继承，例如要求用可见握法替代某术语，或将某名称统一替换为另一名称。仅在用户明确设为长期规则时跨项目沿用；不把单场戏的伤势、咒语、颜色或禁用词变成所有项目默认，也不因此改写其他人物的原始台词。
- 同一片段的意图答案与运镜选择持续有效。“B”只对应紧邻且确实展示过的选项，不猜另一张旧菜单，不解释成未说明的人物动机。
- 开始新创作片段，保留仍适用的项目背景，但重置本段问答状态；明确说“沿用上一段的固定机位”可以继承运动，不能代替本段制作意图沟通。
- 局部修改不重置所有状态。只有改变核心事件、观看目标或使原方案不兼容的变化，才重新处理受影响的意图或运动；不把一个字的修正当成整段重写。
- 发现当前最新要求互相冲突、缺少必需原文或无法辨认选项时，只问决定结果的缺口；可独立完成的审核结论照常提供。已看到的明确设定不要求用户重讲。

## 三、新创作先理解意图，再讨论拍法

新片段首轮提出1–3个具体意图问题并等待回答。“给我完整提示词”“按之前设定”“帮我选”及默认导演权限不自动免除本段步骤；旧片段完成过问答也不代表当前完成。当前明确要求“这次不用问”“跳过提问，直接写”时按其范围执行，必要假设标明，不迁移为长期豁免。

豁免按用户实际限定解释：“跳过意图问题，运镜仍给我选”只免意图；“这次不再提问，直接出稿”免本次尚未完成的意图与运镜提问，AI自行落实可行方案；只说“不用运镜菜单”不免本段意图沟通。

问题优先围绕以下决定，不机械凑满三题：

1. 观众此刻应该先注意、知道、感受到什么，什么信息应延迟？
2. 用户为何安排具体动作、构图或顺序，想保留什么表达效果？
3. 哪些内容已锁定；效果与可读性真实冲突时，哪项优先？

发现、躲藏、偷听等剧情按[叙事前提检查](narrative-conditions.md)优先寻找会改变设计的知情分歧，例如原文未说明是“已被撞见”还是“被发现前藏好”。只在确实不明时占用上述问题额度；已经明确未被发现、禁同框或故意撞见的，不重复问，也不新增确认轮次。

每题包含“已提供的具体观察或原句＋会改变方案的真实分歧＋需要了解的意图”。不重复已说明的答案，不为凑题虚构矛盾；动作拍法细致时，仍可询问尚未明确的观看重点或实际取舍。粗略剧情不要求用户逐个解释所有临时动作，也不问“是否允许优化”等重复授权。

优先用当前可用且适合问题的提问工具，提供通俗效果选项并支持自由补充；工具不可用或适合开放回答时，文字提问并等待。缺少卡片不代表省略问答。每题只承载一个主要决定，不把十几项参数塞进三个编号；普通画幅、设备、焦段和色温自行合理处理。

例如，实际原句是“接触前切到@甲的脸”，可问此处希望观众先预感危险，还是看懂@甲已察觉对手；答案会改变反应依据与切点。不得凭空声称原稿有这个镜头，也不只问宽泛的风格或菜单名称。

回答足够后，按实际内容简短复述观看顺序与保留项，不要求“请确认”。区分“用户说明”与“我推测”，不把选择长镜自动解释为追求沉浸。只对尚未解决的决定性分歧补问，不循环同一问题；没有新分歧就进入下一阶段。

## 四、审核中的确定问题与意图疑问分别处理

纯审核不受新创作的首轮门槛限制。先指出证据清楚的具体问题，再给成立条件或最小修正；有疑问时可在同一回复末尾提出1–3个必要问题。不得以“还不了解制作意图”为由扣住无关的确定结论。

- 同一连续动作、相同机位且没有换手过程，前镜“@甲右手握@乙左腕”，后镜变成“@甲左手握@乙右腕”，可以立即指出接触状态矛盾。身体左右以角色自身为准，不能用画面左右反转解释身体换手。
- 前后门色不一致，若可能看到了不同门面或存在时间跳跃，说明适用条件或询问；若已明确同一门面、连续时间且没有变化事件，直接报告矛盾。不因门色有疑问就隐去已确定的手部问题。
- 背影、画外目标、接触前切反应、故意跨轴等涉及表达选择，按可见线索与已说明意图判断；证据不足则保持条件式，不伪造观察或急判穿帮。
- 只审核不自动加新机位、新镜头或整篇修改稿。需要完整创作改稿时按第一节分流，不把客观审核与创作选项混为一个门槛。

具体核对方法见[意图驱动审核](intent-review.md)与[防穿帮流程](continuity-workflow.md)。

## 五、意图明确后提供3种适配运镜

只在需要创作或重新设计运动的分支执行，不适用于纯审核及不涉及摄影的局部替换。先读[镜头与剪辑库](camera-library.md)，结合[故事构图](composition-story.md)筛选，再呈现候选。

- “固定机位”“缓慢推近”“沿走廊跟到门口”等可执行要求是已指定运动，直接继承。只有景别、角度、“一镜到底”“硬切”或“电影级”不是运动要求；默认微呼吸感也不是用户选择固定机位。
- 意图回答后再给恰好3个适配方案，标A/B/C并推荐一种。各项说明起始构图、摄影机具体运动或保持固定、焦点目标、结束构图、服务的表达效果和主要取舍；不只报术语。
- 每个候选展示前都过同一组条件：首帧、锁定景别/构图、固定人数、场地容量与路径、轴线和视线、关键细节可见性、角色察觉与真实视听条件、禁同框组合、行动先后、台词与结果、一镜到底或剪辑限制。违反任何锁定项的方案先淘汰或重做，不把“需要新增人物/道具、穿墙、离开平台”留作用户接受的隐性代价。
- 三项必须有真正的机位路径、幅度、朝向或观看关系差异，不能仅改名称或焦段冒充不同运动。不机械套用推进/环绕/跟拍；狭窄环境优先考虑可走通的小幅移动、转向或固定观察，不为凑项扩大场地。
- 明确区分：机位位移、原地摇摄、光学变焦、焦点转移、剪辑组织。固定机位加转焦可以说明为“固定观察＋转焦”，不得称为侧移；硬切或蒙太奇不能冒充摄影机运动。一镜到底的三项都须连续。
- 单镜给该镜三项，多镜片段给三套整段摄影组织；已锁定运动的镜头不改，只覆盖未定部分，不默认每镜重选一遍。保持人物、台词、轴线、空间、首帧及故事结果。
- 若严格锁定的条件客观上容不下三种合格方案，先指出具体冲突，只询问一个必要取舍；不要提供明知违规的第三项凑数，也不悄悄放松锁定条件。条件解决后仍回到三种适配方案。
- 等待选择、自定义或看过方案后委托择优，再锁定运动并出稿。不重问已回答的意图，不重弹同一菜单，不附时长选择。仅说“导演发挥”不免除未展示的菜单；当前明确说“不用给运镜选项，你直接定”则按本次授权处理。
- 最终稿只写选定方案，把运动写成“起点→触发→路径/转向→焦点→结束构图”，不将互斥备选塞进正文。不承诺平台必定精确执行；完整库与自定义入口按用户查询再展开。

## 六、逐镜秒数仅按需添加

- 默认“镜号1：……”，不写逐镜秒数、时间码或自行增加总长；不主动问要不要标秒，不在成稿末尾追加时长选择。
- 只有“每镜标秒”“给镜号加秒数”“按秒分配各镜”或明确逐镜时长才触发。仅有整段总长、旧稿带秒数、模型名称或“给我完整提示词”均不触发，也不主动追问。
- 只给整段总长时保留总长与合适节奏，不自动分镜标秒。明确要逐镜标秒但没给总长时，按自然语速、动作、运镜和必要反应自行分配，不强制再问总长；已有逐镜时长优先，指定总长时核对各镜之和。
- 已确认的本片段逐镜标秒选择在当前稿修正中有效；用户最新说“去掉秒数”立即覆盖，合并完整稿不恢复旧秒数。新片段不因另一段或旧模板带秒数而默认标注，除非用户明确将要求延续到当前范围。
- 格式示例“镜号1（4秒）：……”中的数字仅为写法示例。秒数是目标节奏，不承诺模型精确执行；不为凑时长删台词、加速人声或重复动作。总长与必需内容确有冲突时，只询问具体取舍，不另问是否标秒。

## 七、阶段放行与交付

只给本轮所处阶段需要的内容：新创作尚待意图答案就给意图问题；待运动选择就给一组A/B/C；条件满足就内部设计与校核后给稿件。审核先给确定结论，局部修改给请求范围的结果。新写不伪造原稿问题；未看见素材不声称完成审片。出稿不请求重复确认或反复问是否继续，默认不加秒数。

区分修改权限与交付长度：默认修改后给当前片段的最新完整可复制稿，只变更指定项与必要依赖，未涉及内容保持；只有本次明确“只给修改段/单句/差异”才局部交付。原任务只有单镜则仍只给该镜，不扩整集。纯审核、解释和技能维护不触发提示词全文。当前稿全文不可得时不凭空补写缺失内容。


## 八、白模询问与站位配图按需处理

- 配图门槛见[站位图与白模规则](blocking-camera-diagrams.md)：站位图只用于确需中景/全景交代空间的段落；纯近景/特写不自动配图。段首一次锁定位置、锚点与必要图例，逐镜不重复。人数、单镜/多镜或长镜不单独触发图片。
- 只有剧本实际有特效且白模能帮助说明空间或作用过程时，才询问“这段特效是否需要白模辅助？”。优先并入本轮现有的1–3个问题，不增加独立问卷；没有实际特效不询问白模。仅讨论白模功能不等于要求实际出图。
- 同一段用户已经明确要求或同意白模，继续执行该范围，不再复问；新段落不继承无限制白模授权。普通“生成提示词”“按默认直接写”不等于同意额外白模。
- 白模是可选交付。没有回答、未获同意或用户拒绝时不生成，先完成可独立交付的提示词及必要站位图；不得把等待当作授权，也不让可选白模阻断成稿。当前明确不问且未索要白模时直接省去白模。
- 本轮只是更新技能时直接完成规则修改，不为未来的配图询问当下无关的制作问题。
