# 防穿帮：场景可行性、逐镜状态与反例经验

目录：一、场景与原稿；二、逐镜状态；三、关键关系与POV；四、同时动作与容量；五、出稿与出片检查；六、宅邸案例；七、远程攻击案例；八、多人大厅长镜反例。

先按[统一流程](question-flow.md)区分审核、局部修正和创作，再证明位置与动作能成立，安排景别和切点；审核中可确定的矛盾直接报告，不以意图待问为由扣住结论。将规则落实到可见画面；文字检查用于降低风险，不能保证生成视频零穿帮。本文的案例是已查看作品的经验归纳，不是模型能力测试。

## 一、先核对场景与原稿

- 从已有画面或明确文字建立门框、柱子、台阶、通路及主光等固定锚点。区分真实世界位置与当前画面左右，也区分门槛平台、台阶中段、台阶下等不同平面。
- 多素材、到达后交互或暗场揭示按[素材与完成条件检查](reference-state-gates.md)核对：先分配资产职责并检查实际冲突，再确认首帧距离与动作时长，不能用相反的文字当成已经改好图片。
- 检查容纳人数、退步距离、摄影机位置及门扇扫过范围。素材未能证明平台足够宽时，不宣称已确认；可写明必要成立条件，但不擅自扩建锁定场景、移到另一个平面或把建议说成已存在的素材。
- 通读指代与矛盾，例如“不移到石柱边”与“靠在门左石柱上”。先检查是否指不同柱子，统一具体锚点名称；只有仍会改变核心站位或保留项时才纳入最多三个意图问题，不能把矛盾原样复制到成稿。
- 列出本段真实人物及数量，区分角色身份与资产标记。同一@守卫资产被用于两名守卫时，以“门左一名、门右一名”区分位置，不凭空创建第三人，也不声称存在未提供的新角色资产。

## 二、内部建立逐镜状态

按复杂度保留以下必要字段；普通单镜只核对有关部分，不默认输出整张表。

| 状态 | 每镜开始与结束都要核对的内容 |
|---|---|
| 人物与空间 | 真实在场名单与画内可辨名单分别记录；所在平面、相对位置与距离、朝向、入口及移动起点—经过—终点 |
| 场景与背景 | 实际机位允许的前中后景、明确禁入范围；墙面、门窗、灯光与陈设的当前状态及改变它们的事件 |
| 手部与物件 | 哪只手接触哪个部位、握持方向、手臂高度、是否已松开、物件归属与连接；必要时分别记录掌心、手背、指缝及衣物的血迹/污迹状态，特写画外仍继承 |
| 事件阶段与时间表达 | 当前事件尚未开始、进行中还是已完成；是否同一次事件，是否存在明确的回放、闪回、慢放或时间省略；世界中发生的次序与画面展示时长分别记录 |
| 观看与指认 | 看谁、指谁、反应由什么触发；当前机位下的视线和指向是否能让观众辨认 |
| 角色察觉与隐藏前提 | 谁察觉谁、谁仍未知；实际视听条件、状态改变的触发、明确禁同框组合、隐藏完成与来人接近的先后，按[叙事前提检查](narrative-conditions.md)核对 |
| 门与机关 | 哪扇、固定门轴、向哪个空间转动、已开/保持/回摆/关闭、门缝与光带、结束状态 |
| 其他连续信息 | 服饰、伤情、比例、光源开关、可读受光区域与隐藏暗部、揭示触发、声音来源及对口型所需状态 |
| 关键可见条件 | 哪项只须持续存在，哪项本镜必须看清，哪项须隐藏；承载镜号、取景范围、身体可见侧、焦点、遮挡及识别尺度 |

逐对比较“上一镜结束→下一镜开始”。状态变化须有连续动作、可读的动作匹配、已建立的画外过程或明确的时间省略支撑；镜头切换和转焦本身不能改变人物位置或重新抓住已松开的手。未入画不等于离场、增员或停止存在，回到中景时要恢复相同的人数与落点。

本段初始站位与固定锚点只在段首约束一次，不因人数、切镜或特写重复抄写。站位图仅确需中景/全景交代空间时提供，省图不取消内部状态检查。关键节点简洁写出实际变化和末态，再让后镜承接；避免在每镜复制整份设定。不得只写“状态保持一致”而不明确当前接触、位置或开合结果。

用户最新纠正按[跨轮状态规则](question-flow.md)写入相关镜号与依赖，不恢复旧稿错误。身体左/右手与当前画面左/右侧分开记录；换机位不能解释角色自身换手。双语台词区分实际发声原文与释义，OS/VO和画内对白分别保留。

切入嘴部、眼部等特写不自动放下画外手臂、改变握法或解除接触。只记录影响后镜的必要姿态，返回关系镜头时承接；需要调整时安排可见动作或有依据的画外过程，不要求每镜重复完整身体说明。

涉及伤后伸手、抹血、交物或触胸时，分开记录持物与表面状态：“空手”不等于干净，“嘴角抹过”不等于掌心已清洁。以当前素材及用户要求为准；要求无手部血迹时落实起始外观和后续接触继承，保留手部血迹时不能自动擦除。若连续前镜已见血而无清洁事件，不用一句“保持干净”消除冲突，先按可改范围修正起始素材或补有依据的状态变化；接触只支持对应接触部位可能留痕，不能仅因拇指抹血便推定整个掌心染血。无资料时不擅自加血或洗手。

逐镜按[场景可见范围与变化继承](scene-visibility-state.md)检查背景边界，并把场景事件的新状态传递到所有后续受影响镜头及续接段落，不只检查相邻两镜。回到原墙面、门面或陈设时承接最新状态，画外与旧场景资产不使变化重置。

## 三、用画面证明关键关系

- 先核对人物实际面向、前后距离和靠墙关系，再判断屏幕左右。沿一条空间线前后站立的人，从侧面可以投影为横向排列；“不要并排”不能替代明确的朝向、落点与间隙。只有画面证据足够时才断定实际站位错误。
- 复杂或曾生成错误的握法，用手别、接触部位、物件从拇指侧/小指侧伸出的方向及尖端朝向表达到足够辨认为止；必要时补充靠近护手或柄尾的手指位置。不机械逐指罗列，不在所有任务中禁用“反握”等术语；用户明确不用术语时改用可见关系。
- 拔刀、开门、拆卸先核对实际资产中的开口、门轴、挂点和活动空间。未见素材便标为待核验条件，不凭名字推断结构或宣称通过。抽出路径先服从开口轴线，脱离后需要调整朝向时再明确转腕，不通过折腕、穿身或搬移挂点解决冲突。
- 抓握、攻击或搀扶的接触高度核对身高、姿态、臂展、距离与道具长度；先用既有姿态或允许调整的动作形成可达条件。体型差另按[尺度与重量](scale-weight-combat.md)检查，不缩放人物、拉长手臂或擅增台阶。
- 运镜起幅、途中和落幅分别核对可见人数、动作空间、遮挡、背景与主体尺度；横摇改变观看方向，不自动推近或缩短人物距离。局部特写切到完整操作时，允许在授权范围内调整景别与取景容量，不让模型为凑同框移动角色或放大道具。

- 切入第一人称POV时重新确定视角主人、实际眼位与朝向、可见的自身身体部位、其他画内人物。无镜面、分身等剧情依据，不让视角主人的另一完整身影出现在自身视野；允许符合视线的自身手臂或俯视躯干，不能把所有自身部位一律禁止。全段人数限制不能代替每镜可见名单；正常过肩镜头不套用第一人称限制。
- 分开记录说话对象、注视对象和手势对象。切镜后按新机位重新核对各自屏幕方向；镜外手臂仍延续原指向。关系已在上一镜建立时，可收紧面部特写让手臂真正留在画外，只呈现头眼转向；需要保留手时，必须让新构图中的指向仍可读。

按[故事构图](composition-story.md)核对实际摄影机而非仅空间参考视角，检查开始、关键动作与结束构图。伤口或门缝“持续存在”不代表本镜“看清”；需要看清时落实角度、尺度、焦点和遮挡，用户要求画外隐藏时不擅自入画。

- 已有关系画面足够时直接继承；关系不清且允许调整时，用中景/关系景或连续运镜交代空间。用户指定特写开场时可稍后揭示，不强制每段以全景开头。
- 抓握、松手、交物、推开、命中等优先在容纳双方的镜头内完成关键变化，也可用匹配切镜接续。写明触发事件与唯一发生次序，不能让声源、反应和松手前后颠倒或重复表演。
- 指认有多种可能对象时，优先让发出手势的人、指向路径与目标同框；或用此前已建立的空间、匹配视线与目标镜头衔接。检查前景肩部是否会成为错误的指向目标，不在只见甲和乙的构图中无依据地要求观众读成“指向丙”。
- 当前目标需要被认出时保留足够的衣着、轮廓或必要清晰度；柔焦不抹掉指认关系。只有台词“她/他”或一句“不能指错”不足以替代构图中的依据。
- 用户有意隐藏目标身份、保留画外信息或只展示反应时，保留这种设计；用已知方向、声源和后续揭示建立因果，不为了同框而提前露脸。关键信息与隐瞒目标冲突且未获取舍时，再作针对性提问。
- 对观众隐藏与对故事中某角色隐藏分别校核。发现、躲藏或偷听时按[叙事前提与角色察觉](narrative-conditions.md)检查实际视线、注意力、声音和动作时机；人物在画外或柔焦不证明对方未发现。当前明确禁止同框的组合，在摄影机运动中途也须保持。
- 过渡中景核对同一场景平面、距离、人数和接触状态；改变景别不能把门槛前变为台阶下。涉及三人交互时，分别记录当前说话者、听者和手势目标，不把所有动作目标绑定给过肩前景人物。

## 四、控制门扇、人数与同时发生的变化

- 手部特写以手部变化为主要任务；决定后续位置的侧撤、转身、靠墙等走位，不仅靠失焦背景交代。在允许范围内调整附近镜头或景别，使必要落位先被读清，再接依赖它的动作；不机械增加全景或冻结配角，也不违反已锁定的一镜到底。
- 已知总长时，将完整对白、动作准备与完成、反应、路程和镜头切换一起检查。说明拥挤发生在哪里；合并重复信息或建议分段时保留核心剧情与台词，不用加速表演或跳过完成条件硬塞。仅给总长不自动标逐镜秒数，也不主动询问秒数。

- 给出门扇完整阶段：起始角度/开合状态→谁或什么令其运动→人物通过的空隙与路径→停止/回摆条件→最后状态。门轴和扫掠空间固定，人物避开门扇路径；保留缝隙、半开和完全合拢是不同结束状态。
- 门缝变化时，光带及相关遮挡随之变化。门不需承担剧情信息时，可建议保持稳定；必须保留风动或机关变化时，用独立的清楚阶段或细节镜落实，不悄悄删除该动作，也不把阴天光重置成另一种天气。
- 固定人数分别指定位置、职责和是否移动。新增出场需有剧情依据与入口；远景、柔焦或切镜不能自动制造替身、第三名守卫或多出的同伴。
- 每镜只安排能读清的核心变化，让其他人物处于自然的观看、等待或持续行动状态；并非冻结所有配角。复杂动作可在允许范围内拆镜或分阶段描述，保留原有情绪重点与必需剧情。

## 五、出稿检查与出片检查分别进行

### 出稿完成条件与修改回归检查

以本轮实际要交付的完整正文为检查对象，不只检查刚改过的一段。内部用前文的最小状态表记录有关事实，不输出推理过程，不默认向用户附整张表，也不要求用户重复提供已有信息。

1. **动作阶段**：逐个关键事件定位起点、当前阶段、完成条件与触发；连续叙事中不能前镜已完成、后镜无依据退回进行中，也不能重复发生一次性事件。明确的闪回、回放、慢放和时间省略按其依据判断，不一概禁止。
2. **相邻起末态**：逐对核对前镜结束与后镜开始的实际位置、朝向、支撑、手部接触、道具和效果阶段。允许有依据的画外过程或动作匹配，但须能指出状态改变的依据；仅切近景不自动复位姿态。
3. **机位可行性**：核对摄影机相对对象、可用空间、朝向、遮挡、焦点与实际背景，并覆盖运镜起幅、途中和落幅。按[构图检查](composition-story.md)区分人物正面与道具展示面、横摇与位移、柔焦与画外；实际尺寸未知时保留成立条件，不假装已做三维验证。
4. **镜头容量**：核对景别能否呈现本镜必须看清的关系，以及动作准备、过程、反应和声音能否容纳于已定节奏。存在不相容要求时指出具体障碍，例如大面积前景遮挡期间仍要求同时辨认被挡细节。没有数据不能自设硬性镜数或秒数阈值，也不能用加速表演硬塞。
5. **公共约束与修改残留**：对照逐镜正文、整体设定、资产职责、声音与结尾，核对同一事件的次数、位置、持物、效果来源和触发是否一致。局部具体描述不应无说明地与公共约束冲突；最新纠正覆盖旧版本，必须同时清除相关旧表述。

修改时先列出本次变化及受影响的字段，再定位依赖镜头：包括前镜末态、后镜首态、隔镜重现的同一状态、画外动作、声音和环境后果。更新这些必要依赖后，通读当前全文寻找旧状态和重复动作；不能只用关键词替换，不能借回归检查重写无关剧情、台词、拍法或新增时长。

一镜到底将同一套起末态检查用于镜内连续阶段，按[长镜与旁听表演](continuous-take-performance.md)核对摄影机从哪到哪、动作开始前的取景、正常时间与反应触发。正文直接描述连续运镜，不使用机位序列；镜内转向不使物件、门扇或画外人物复位；旁听者的微反应不能擅自改变已定站位、持物或知情状态。

每项结论区分“文字关系成立”“依赖未核验条件”“存在明确文字冲突”。有明确冲突时，改稿任务先在授权范围内消除，纯审核任务直接报告而不改；确需用户取舍的锁定冲突才提问。未知素材或模型执行风险不自动阻断可完成部分，不得把它们写成已通过实拍或视频验收。完成有效核对后按审核停止条件结束，不为凑问题继续加限制。

有视频时按实际画面核对，不假装检查过没有提供的素材；没有视频时只能确认文本是否自洽。审片区分：

- **连续性矛盾**：同一连续动作中接触对象换了、持物无依据换手或状态前后无法接续。
- **与提示词不符**：镜内可以成立，但人数、位置、剧情或最终门缝状态没有按要求呈现。
- **构图/指认不清**：画面允许多种解读，不能仅凭前景位置断言真实三维指向。
- **有依据的省略或隐藏**：画外走动、时间省略与有意隐瞒能够被前后信息支持，不直接判瞬移。
- **证据不足**：未看见的手别、遮挡处或声音不作确定结论；把原因猜测与可见事实分开。

实际制作可先分别核对入场、接触变化、指认等关键段落，再继续衔接。仅在用户要求制作流程时给出生成/重生成建议；不自动调用图片、视频工具或假设特定平台支持某种控制功能。

## 六、经验案例：宅邸门口撞见（穿帮视频1）

地下拍卖场案例补充见本页末尾；两例均只迁移检查方法。

本案例源于本次已查看的《穿帮视频1.mp4》及用户给出的提示词，只保存文字经验，不依赖技能外的视频路径。可核对的画面与预防方式如下；时间为审片定位，不是视频提示词的默认时长。

| 原要求与可见问题 | 判断 | 改成怎样的设计 |
|---|---|---|
