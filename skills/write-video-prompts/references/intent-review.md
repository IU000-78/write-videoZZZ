# 基于事实与制作意图的逐镜审核

先按[统一任务分流](question-flow.md)确定范围。纯审核立即报告已有证据支持的问题，不等新创作问答或新运镜选择；只有依赖未知意图的判断暂缓，其他确定结论照常交付。需要改稿时，再区分局部技术修正与重新创作，分别进入相应分支。

## 一、建立简短的判断依据

用制作人实际表达的内容组织以下信息，不强迫填表，也不把空缺都变成问题：

- 观众在这个节点应看见的内容、应知道的信息、应感受到的情绪。
- 观众还不应知道什么，信息何时以及通过什么画面揭示。
- 动作、构图、景别、运动、切镜次序为何这样设计，哪种效果优先。
- 必须保留的具体内容和可以调整的实现方式。
- 冲突时愿意牺牲什么，以及不能接受的损失。
- 仍属于审核者推断的部分及其依据。推断不能升级为用户明确要求。

已知意图足够时，可按实际信息简述观看重点与保留项；不机械填满模板，不把未回答内容写成用户的理由。没有这些信息时，先审核可确定的部分，把需要意图才能判断的条目标为条件式并单独提问；不问“请确认我理解得对不对”。

## 二、逐镜审核

按用户原镜号检查，每个有意义的判断都落在具体原句、实际可见素材或前后镜关系上。避免为每镜机械罗列相同检查表。

先用[防穿帮流程](continuity-workflow.md)核对场景可行性、原稿歧义及逐镜起末状态。审片时分别记录“连续性矛盾”“与提示词不符”“构图/指认不清”“有依据的省略或隐藏”“证据不足”；缺少过程不直接等于瞬移，不凭一个前景肩部就断言真实三维指向。已确定的画面事实与解释、原因猜测分开。

1. 找出该镜承担的表达任务，说明与制作人目标的对应关系。
2. 检查观众实际上能看到什么、什么时候知道什么，原稿提供了哪些可见线索。
3. 判断动作起末态、人物距离、方位、视线、受力、光源、持物、伤情和声音是否连续。
   另核对人物所在平面、固定人数、左右手的接触对象、门扇开合阶段与最终状态；将每镜结束状态逐项接到下一镜，不让各镜独立重设。
4. 按[故事构图](composition-story.md)检查景别容量、实际机位、路径、焦点、遮挡、对白和剪辑次序；分别核对首态、关键动作和末态。明确要求看清的细节是否真的可读，而不只是被写成持续存在；实际发声语言是否明确，译文是否被误读、OS/VO是否被误绑定口型。
   发现、躲藏、偷听等另按[叙事前提检查](narrative-conditions.md)核对各角色的察觉状态、视听依据、禁同框组合与行动先后。反推危险对象此刻能看见或听见什么，不把画外、柔焦或特写当成实体遮挡；缺少当次完整提示词时，分开记录画面问题与原因未明。
5. 说明结论、成立条件或阻碍。局部严格修改给最小必要调整；允许导演重构的任务按[导演发散设计](director-design.md)主动比较并实施更有观看价值的方案，不止消除错误。

可使用以下结论形式，不必每镜全部输出：

| 情况 | 判断与处理 |
|---|---|
| 设计能够成立 | 解释为何能实现目标，补充所需的视线、声源、路线、反应或揭示节点；不为展示审核能力强改 |
| 意图合理，描述不足 | 指出欠缺哪条可见线索，使原意通过具体描述落地 |
| 意图合理，当前拍法阻碍实现 | 按“想实现的效果→当前设计如何阻碍→怎样调整仍保留核心想法”说明，不只说难生成 |
| 明确的空间、动作、连续性矛盾 | 引用矛盾两端，说明为什么不能同时成立，提出符合意图的修正 |
| 仅属审美偏好或不同做法 | 标为可选建议，说明其收益与代价，不把个人偏好写成技术错误 |

“有挑战”不自动等于不能拍；“作者有理由”也不等于设计已能成立。只有原稿、素材和明确意图能支持的结论才作为确定判断。

技术错误与导演选择分开说明。主动作出的视觉优化可以直接实施于允许改编的部分，并说明其表达收益；不必因它属于创作选择就逐条要求批准，也不能把个人偏好冒充客观错误。

## 三、隐藏信息、延迟揭示与打破常规

- 先区分角色知道什么与观众知道什么。角色在画外看见信息时，观众可以暂时只见其反应；检查声源、目光、此前信息或后续揭示是否提供足够依据，不强制把画外对象提前拍出。
- 各角色分别知道什么也须区分。@甲已发现@乙不自动等于@乙已发现@甲；“没认出身份”与“没察觉有人”不是同一条件。用户明确不许两组同框时按本段限制审核；无此限制且有可信遮挡或注意力依据的同框不自动判错，故意被撞见也不得被改成隐藏。
- 背对镜头可以用于隐藏表情、保留身份、制造疏离或延迟出场揭示。判断肩颈、姿态、停顿、声音和背景能否支撑目标；不因看不到脸就要求改成正面特写。
- 接触前切反应可以制造预期、误导或表现察觉。检查反应依据与揭示时机；若原稿实际要求“受击后才痛”，却在受击前出现受力反应，仍指出因果冲突。
- 故意跨轴、跳切、破坏稳定构图等先评估是否服务既定效果，以及观众能否凭锚点重新建立关系。常规电影规则是工具，不能替代制作人的表达目标。
- 蓄意省略过程与无意的瞬移要区分：剪辑、时间跳跃或风格化依据可支撑省略；同一连续动作中门轴换边、接触对象变化、同次攻击重复命中等仍是具体矛盾。
- 不凭创作意图抹去画面中的客观问题；也不把所有未展示的信息都叫穿帮。

## 四、情绪与特写建议

- 从制作人要观众感受和暂时不知道的内容出发，判断是否需要特写、特写何时出现以及应露出多少信息。
- 联看相邻镜头，按[特写密度与中景过渡](shot-transitions.md)检查重复表情、逐句切换与动作空间不足。指出具体由哪句台词、哪个起身/转身/离场动作触发换景别；允许修改时，优先将附近的重复特写改成承担实际行动的中景，避免只加一个无信息的空镜。
- 以行动角色为视觉重点时，让其清晰、其余人物柔焦但位置连续，保留去向与必要空间锚点。中景承接上一镜末态，不重复说话、起身或迈步；一镜到底用连续重构景别完成，固定景别或“只改X”的明确要求不能被过渡规则覆盖。
- 分别检查角色的内在情绪、角色愿意表现出的外在情绪、观众此刻应该读到的情绪。三者不同可以成立，不强制写成同一种表情。
- 把抽象情绪落实到眼神目标、呼吸、嘴角、下颌、肩颈、手部和动作停顿；不自动升级为流泪、怒吼或夸张表情。
- 有意隐藏面部时，优先讨论背影、手部、距离、声音或延迟反应如何表达；需要脸部信息时说明揭示它会带来的收益与悬念损失。
- 动作接触与面部情绪不能同时被某一景别容纳时，依据用户已说明的优先级调整构图、调度或切点；不未经说明删掉必须保留的动作。
- 给建议时说明具体位置、希望加强的效果和会付出的代价。不把“再加一个大特写”当作每段必需的优化。

## 五、修改稿与交付范围

### 审片事实与原因分开归类

对每项实际问题先记录可见画面，再对照原文；下列为原因判断，不替代画面问题分类，同一问题可同时具有执行偏差与设计风险：

| 归因 | 需要的依据与表述 |
|---|---|
| 文字明确矛盾 | 引用不能同时成立的要求，直接修正文义或状态依赖 |
| 设计存在漏洞 | 指出未交代的可见范围、目标关系或完成条件；表述为可降低风险，不声称已证明唯一原因 |
| 模型未执行明确要求 | 原文已清楚写出数量、顺序或位置而成片偏离；不能反过来声称原文写错 |
| 证据不足 | 缺原提示词、实际首帧、资产或关键画面时，列明尚不能判断什么，不猜定素材权重或模型机制 |

只依据既有审片记录时注明来源，不冒充本轮重新看过视频。文字自洽、文字任务试用与视频生成验收分别说明。

声音证据单独核对：只看抽帧或波形不等于听辨过音轨。无法听辨时，可分析文字声线设计与用户已报告问题，明确来源，不自行断定具体音色、发音或混音缺陷。

### 审核停止条件与修改收敛

- 完稿前按[出稿完成条件与修改回归检查](continuity-workflow.md)实际核对当前正文。报告时将本轮能直接定位的文字错误、依赖真实资产的成立条件、只在成片中才能判断的执行问题分开；自己生成的明确矛盾应先承认并修正，不把责任推给视频模型，也不把技能文件中已有某条规则当成该规则本轮已经执行的证据。
- 每条问题须能定位原句、素材事实或状态依赖；将确定错误、条件性风险和可选审美建议分开，不为连续审核凑新问题，也不把同一问题改名反复提出。
- 人物关系、可见范围、动作起末态及触发顺序明确，且素材没有新增冲突时，结束文字审核。剩余模型执行不确定性说明为剩余风险，不用无穷追加否定词追求“绝不穿帮”。
- 修正具体障碍及必要依赖，合并重复约束；完整重发时保留无关原文，不借精简删掉台词或锁定动作。规则清单留在内部，只将影响画面的必要条件写入提示词。
- 用户需要后续制作验证时，可建议关键帧或短片段核验，先确认现有工具与入口能力；不强制增加生成、费用、插件或假设平台有未核实的控制功能。只有实际完成验证才报告已验收。


- 用户要求“审核并修改”时，依次交付：简短意图复述、必要的逐镜审核、相关的情绪与特写建议、完整可复制修改稿。段落多少按问题数量控制，没有必要的问题不凑条数。
- 上述顺序只组织已可交付的内容，不能把未确认意图冒充已理解。需要新创作问答时，先给确定审核结论与当前问题，待答案满足流程后再交对应改稿；最小局部修正不重启问卷。
- 用户只要求审核时不强加改写全文；要求提示词时在内部完成上述检查后给正文，默认镜号不加秒数，不主动询问是否标注。只有用户明确提出逐镜时长需求时才按[按需时长规则](question-flow.md)添加。没有原稿的新写任务做方案校核，不能伪造“原稿问题”。
- 修改保留用户台词、角色标记、核心剧情与人物关系、既有画幅、必须保留项及明确的信息揭示要求。局部修改保留镜号并只改指定范围；整段导演重构可以重排、增减非锁定镜头与连续编号，调度和呈现顺序仍服务原意。
- 修改后默认按当前片段范围返回最新完整提示词，同步必要状态与已获要求的时长，不只给替换段；本次明确只要局部文字时例外。纯审核仍只交结论，不因完整稿默认而自动改写。
- 用具体画面将意图传递给SD2.5：谁在何处、此刻露出什么/隐藏什么、动作与反应顺序、构图/路线/焦点、切镜触发点、声音与结束状态。除非用户要求，不把审核术语和内在意图问卷塞进生成正文。
- 默认不加逐镜秒数，也不主动询问；用户明确要求逐镜标注时才分配并核对指定总长，仅指定总长不自动给每镜加秒数。不自动加入BGM或字幕，不无依据改变主要剧情；允许主动补充有因果的微动作、反应、环境互动与视觉呼应。遵守参数省略约定、真实比例、自然表演、轴线与空间约束；有意偏离之处写清可见依据。
