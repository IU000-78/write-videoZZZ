# 素材冲突、到达切点与暗场揭示

用于多张素材分工、走到某处再交互、短时长进出门、暗场或延迟出场。先按[任务分流](question-flow.md)处理；已确定片段的修正直接继续，不重启问卷。只把本镜必要约束写进正文，不向每个提示词复制整份检查表。

## 一、先检查实际输入，不靠文字宣布冲突已解决

- 同一角色的多个状态资产，分别指定身份、形态或局部姿态职责和使用阶段。资产名中的“握拳”不自动要求全身重置为该姿势；张掌时只继承仍适用的外观。将“变成某资产”落实为具体部位的变化，不因更换引用而重置伤势、接触、位置、服装或背景；没有看过资产时不猜其画面内容。
- “承接上一段构图”须与当前站位及实际首帧相容。背景与站位疑似冲突时，先核对摄影机位置和朝向；能由真实反打解释的不同背景不判换位。素材缺失时只给条件判断，不宣称素材与文字已统一。

- 给每项实际使用的素材分配职责：人物身份与服装、道具造型、建筑外观、空间布局、照明状态、首帧构图。只约束该素材负责的内容；布局图不是实际拍摄视角，也不自动提供家具、地毯、装饰或灯光。
- 姿势图另指定适用阶段及身体部位：起身中的支撑、运动途中的持物姿态、抵达后的落位不能混为同一末态。静态参考只锁定获准参考的姿态，不代替进入和离开姿态的动作；核对人物自身手别、支撑与可达范围，不复制人偶外观、展示支架、文字或无关背景。用户只参考上身时，不把图中双脚或悬空摆法强加给角色。
- 对照用户最新设定检查素材中的台阶、门面、家具、灯光、人数及起始距离。写出“已一致／画面冲突／尚未查看”，不把未见素材说成已经修好。
- 文字优先表达用户意图，但不保证生成工具会覆盖相反的图像信息。首帧门很远时，不能仅写“只剩两步”就视为可执行；带台阶的门图也不能因正文写平地而视为已改图。
- 在授权范围内选择相符资产、调整起幅构图或提出必要的素材修正。不能修改锁定首帧时，保留其真实起点，调整获准修改的时长或明确时间省略；不能暗中搬近门、缩短走廊或改变人物步速来消除距离。
- 完整提示词只引用本段确有用途的资产；未拍清的家具不必重复描述全部外观。不要因用户给了全景图便安排一个展示全场的镜头，提前泄露人物或空座位。

## 二、按动作完成条件切镜

- 连续攻击也建立完成条件：必要落位完成→蓄力释放→飞行逼近与迎挡→接触受击→走近→抓握。按本段真实因果选择节点，不把示例变成固定剧情。每镜只承接当前阶段，不在命中后重新插入同次攻击的蓄力；明确的闪回或时间重排另行标明叙事依据。允许动作中匹配切镜，不要求每个动作都拍完才切；必须完成的是下一动作依赖的条件。

- 对“到达→接触→操作→通过”等依赖链，明确后一动作的必要条件和前镜的可见末态。例如连续抵门推门：走到门面→站稳→掌心接触门板，才切到承接同一触点的推门镜头。
- 核对首帧真实距离、步数、自然步速、对白和运镜是否能在已定时长内完成。镜号秒数是节奏目标，不是动作完成的证据；不要只因时间到了就把下一镜人物放到终点。
- 时长不足时，优先在允许范围内让起点更接近目标、缩短非关键等待、重新分配各镜时间或拆分生成。不得加速对白、重复起手、跳过必需支撑或靠“动作自然”掩盖缺口。
- 用户允许省略行走时，可以用有空间依据的时间跳跃，不把所有切镜都判成瞬移。当前要求连续完成时，必须让前镜末态与后镜首态相接；两种写法不能混用。
- 连续到达没有完成时，不给出“衔接已经解决”的结论。文字方案自洽与成片实际完成分开说明。

## 三、把真实在场、画内可见与被角色察觉分开

- 内部分别记录：真实在场名单及固定位置、本段可辨认的人物、需要隐藏的目标及隐藏依据、后续揭示的触发事件。另按[叙事前提检查](narrative-conditions.md)记录谁察觉谁。
- “实际只有两人”“本镜只看清两人”“第三人一直在但被黑暗遮住”是不同状态。场内已有隐藏人物时，不用全局人数限制把他排除；写明他仍在原位，本段不可辨认。
- “画面只出现两人”本身是画内限制，不能据此断言第三人被删除或认定模型漏人的原因。只有与已知在场状态、可见座位或后续揭示不相容时，报告具体冲突；否则将未显式锁定的位置和隐藏依据列为执行风险。
- 让隐藏条件在首态、运动中途与末态都成立。目标位置若被灯光照清，即使人物没画出来，也不能把清楚的空座位当成“人物藏在暗处”。允许调整构图时，让该区域处于画外、真实遮挡或无细节暗部。
- 揭示时延续同一人物、座位、姿态和位置。灯亮、转头、开门或镜头变化只揭示原有状态，不凭空召出人物，也不借切镜换座位。
- 尊重用户真正限定的无人场景、固定人数或露脸要求，不为套用本例擅自添加隐藏角色。角色不存在与角色未被看见不互相替代。

## 四、用可见范围定义暗场

- 区分“整体昏暗但家具可读”和“某区域无可辨认细节”。按剧情写出哪一部分仍可读、哪一部分必须隐藏；只有“夜晚、漆黑、冷灰”不足以承担延迟揭示。
- 分别记录光源和受光范围：火盆是否点燃、天顶是否有直射光、入口是否有暖光溢入、环境反射照到哪里。关掉光束不是把白光改成蓝光；背景虚化也不等于背景隐藏。
- 跟随人物背影入门时，走廊在摄影机后方的光通常照到部分肩背与入口地面，不一概写成纯逆光轮廓。越往纵深，入口光自然衰减；不能为保证所有细节可读而把整间房自动提亮。
- 延迟开灯的片段，明确触发之前／之后的照明差异。揭示前不展示目标区域细节；触发后同一固定光源照出原本就在场的人物，光源不随人物移动，除非剧情明确如此。
- 当现有资产的灯光与暗场冲突时，指出需要改用相符暗场素材或收紧拍摄范围；不承诺多加否定词就能锁定曝光，也不擅自发明平台的曝光锁定参数。

## 五、已审片案例：地下拍卖场入室

依据《穿帮 2.mp4》约14秒成片及当轮提示词记录，保存可迁移的文字经验，不依赖技能外的视频路径。

| 实际可核对的画面 | 提示词或判断的缺口 | 下一次怎样检查 |
|---|---|---|
| 约6.5秒人物仍与门隔着一段通道；约7秒切到手已贴门 | 前镜只写走到停下，后镜直接从抵门开始；未把真实起幅距离与时长核对 | 连续抵门段结束在实际到达和掌心接触，下一镜承接同一接触 |
| 开门后深处已有冷色顶光，王座与地面可读 | 写了熄灯与暗场，也保留了弱环境光和纵深场景展示，未给隐藏区可见性验收 | 分开约束入口可读范围与深处不可辨区域；灯光揭示触发之前不展示目标细节 |
| 入室末段王座被展示，却没有可辨认的阿忒翁 | 原文限制画内两人，但没有显式锁定第三人的在场位置与隐藏依据；空场景资产与角色状态的职责不清，仅属生成原因风险 | 真实三人在场但本段只辨认两人；第三人在固定座位，揭示前不拍清该区域 |
| 门前仍出现台阶 | 最新文字已要求平地，但画面结构仍冲突 | 检查实际门图及首帧，必要时修正素材；不能仅凭正文宣称已统一 |

以上能证明成片偏离设定和文字存在风险，不能证明模型内部的素材权重、自动曝光或确切生成机制。把“可能沿用素材／可能将隐藏理解为缺席”标为原因推测，不推卸给平台，也不声称单次修改已验证零穿帮。

## 六、出稿前的四个追问（内部执行）

1. 当前资产或锁定首帧是否仍与空间、光线、人数或起始距离相反？矛盾是否实际处理，而非只添文字？
2. 每次交互开始前，必要的到达、接触或支撑是否已发生；上一镜有没有给出需要的可见末态？
3. 哪些人一直在场但本段不可见；从实际机位移动和受光范围看，隐藏是否维持到规定触发？
4. 最后画面是否兑现门、位置、照明和揭示状态；当前只能判断文字，还是确有成片可供验收？
