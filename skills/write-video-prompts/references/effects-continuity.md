# 特效来源、阶段与跨镜连续性

凡任务中已有特效描述，自动应用本页；无特效的任务不新增效果或特效尾注。先按[任务分流](question-flow.md)处理，新创作、审核、局部修改沿用各自流程；补清既定效果不重启问卷。本文是用户迭代经验的提示词写法，不是平台控制参数、模型能力测试或一次生成保证。

目录：一、资产与来源；二、可见阶段；三、跨镜进度；四、瞬移、时间与空间作用；五、音效；六、局部编辑与满屏转场；七、短例、依据与检查。


配图另按[按需门槛](blocking-camera-diagrams.md)：实际特效只提供考虑白模的前提，不自动生成。确需白模辅助时先询问用户，同段已有明确同意不复问；未同意就用文字完成特效来源、阶段与连续性。特效不单独触发站位图，纯近景/特写仍省站位图，不因白模图把每镜扩成整套资产。

## 一、先确定资产与真正的效果来源

- 查看实际可读取的道具、人物及特效素材，区分入鞘、部分出鞘、完全出鞘、变身前后等状态。图号、文件名或文字与画面相反时，指出实际可见状态；能依据上下文明确对应便按状态写，仍无法决定时只问影响结果的一处，不猜未见内容。
- 原样使用已有 @资产名。多个状态资产可以描述同一物件，明确哪个阶段使用哪个外观，不因此生成第二件道具；“最新版”只有确属资产名时才写进标记。
- 先锁定效果附着的具体部件，再写它向哪里运动。物件分离后，雕饰、符文及发射部位跟随所属部件；例如骷髅位于刀鞘，拔刀后仍留在刀鞘，不转移到刀柄或刀身。固定装饰不因发光或冒烟自行张嘴、变成生物，除非剧情明确要求。
- 区分素材职责：造型图锁定轮廓与材质，特效图锁定已指定的形状，布局图只辅助空间。不要引入白底、展示台、并排道具摆法、标注或参考图中的无关布景。
- 区分并存的效果来源，例如道具符文与护手溢烟、外眼角薄雾、身体瞬移残影分别附着不同部位。颜色相同不等于同一个发射源；连续冒烟写明持续溢出，不在每次切镜重新喷发。只把当前确认的部件写入正文，不把案例位置变为通用设定。
- 用户以作品作参考时，提取所需轮廓、流向、脉冲、折射或节奏，不只写作品名。实际素材不可查看或入口不能使用视频参考时，改写为可见、可听描述，不虚构已看过参考片段，也不保留无法输入的素材标记。

## 二、将效果写成可执行的阶段

内部核对下列要素，正文只保留本镜需要的具体信息，不逐镜抄表：

| 要素 | 必须能回答的问题 |
|---|---|
| 来源与形状 | 从谁、哪件物品的哪个部位发出？数量、轮廓、颜色及纹样由哪个已定资产控制？ |
| 触发与演变 | 在接触、握稳、说完、命中或其他哪个动作之后起效？各阶段按什么顺序变化？ |
| 动作进度 | 覆盖是否跟随出鞘、抬手、挥击或显形的实际进度，切回后是否接着发生？ |
| 路径与范围 | 从哪里到哪里，贴附、环绕还是向外发射，影响主体局部、场景区域还是整个画面？ |
| 可见性与环境 | 是否遮住口型、手指连接、握柄、刀尖、攻击接触或目标？反光与环境响应是否有依据？ |
| 结束与声音 | 在哪个动作阶段收束、消散或留下痕迹？适用音效是否对应一次触发及实际空间？ |

- 用动作事件限定先后与持续区间，不默认增加逐镜秒数或无法验证的平台参数。一次变化只启动一次；多个效果按必要阶段分开，不把变色、浓烟、爆闪、空间扭曲和镜头剧烈运动堆到同一接触瞬间。
- 将抽象词转成能观察到的变化：威压要有获准的身体受力或局部环境响应；气浪要有从源头到目标的一道移动前沿；空间扭曲要指出哪一带背景轮廓经折射暂时错位；金光铺屏要交代亮区如何扩展到四边及末态还能看见什么。只选服务当前意图的证据，不把所有表现手段叠加使用。
- 强度用可见证据表达，例如前沿轮廓、人物迎风衣料和一层尘粒的先后响应；不要只反复加“巨大、震撼、明显”。用户要求克制时保留幅度，不为证明效果擅加破坏、飞退或发光双眼。
- 颜色与形状分别锁定。变色不等于图案变形，不让固定符文自动变成其他文字或法阵；明确来源不同的效果可以维持各自颜色。
- 区分镜内渐变与切镜后的阶段变化。用户要求每次切回变一种颜色时，各次画面只呈现当前阶段，结束状态传入后镜，不在每镜重演整套变色；具体颜色和切镜方式只继承当前任务。
- 将“变黑”写成可见状态，例如原有亮光熄灭、眼窝变深黑或出现明确的暗色能量。不要无依据将黑色当作普通照明光源；用户明确要求超自然黑光时保留意图并描述可见结果，不擅自取消。
- 按透明度、密度与边缘流动描述烟雾，不改变已锁定道具轮廓。需要看清刀尖、符文或口型时，把烟雾放在侧缘或局部，不以“保持清楚”代替实际取景和遮挡处理；明确要求遮住或延迟揭示的部位仍按用户意图隐藏。
- 按光源位置、强度和当前覆盖范围安排照亮与反射。局部发光影响邻近表面，不能无故把整厅染色；明确要求强光铺屏时允许按阶段增亮、覆盖人物，不让通用“不过曝、始终清楚”取消指定结尾。新增强光、伤势、破坏、尘土或环境变形须有当前剧情依据。
- 简短按“来源与初态→一次触发→主要变化→可见结果与末态”组织。先后关系用“先、随后、到达后”表达；确实同时的声层或效果才写同步，不用一句话同时承载多次出入、变身、传播和复杂运镜。

## 三、绑定动作进度并承接切镜

- 分别锁定飞行形状、透视变化、接触范围和命中残留。既定多道刃束记录数量、排列与相对间隙；接近镜头仅整体透视放大时，不把它改成新增、分叉或向两翼展开。剧情明确要求分裂时，写出分裂触发与数量变化，不一概禁止。
- 攻击被身体格挡却同时损坏后墙时，说明攻击与肩宽等参照的关系、哪些部分越过身体轮廓、怎样到达墙面；无法成立便调整获准修改的范围或受力路径。持续石材损伤另定数量、走向、排列及材质，临时光雾消散后留下裂槽和碎屑，不默认残留成发光纹路。具体数量、颜色和尺寸只继承当前项目，不套用案例值。

- 渐进出鞘：效果只先附着已露出的刀根，再随新露出的刀身蔓延，完全拔出后才进入完整刀身与持刀手的环绕阶段。刀鞘与挂点留在原位，刀尖、握柄和关键符文保留指定可见性。
- 渐进覆盖不限于拔刀：沿已经发生的动作或实体表面发展，不提前覆盖尚未出现的部位，不靠切镜替换成完成态；瞬间起效是当前明确要求时，按该要求执行，不强行改成渐进。
- 眼神与手部快切共用同一次出鞘、蓄力或变身进度。镜外效果继续到当前阶段，切回不重启变色、冒烟、握柄或发力。
- 内部记录“尚未起效→发展中→稳定持续→退出后”及各镜起末状态；不必把这张状态表交给用户。局部修改同步更新依赖的声音和后续状态，但不改无关台词、站位、拍法或剧情。

## 四、区分超自然运动、背景柔焦与时间规则

### 力场、空间扭曲与气浪

- 先判断要表现贴身压制、局部空间折射，还是远处袭来的一次冲击波。来源、形态与传播关系不同，不把“环绕身体的蓝圈”“球形罩”“从墙上推进的前沿”当作同义词；用户改选其中一种时，删除旧方案的来源、包覆形状和触发要求。
- 远处气浪采用“固定来源亮起/蓄势→一道前沿离开来源→沿既定空间推进→到达人物→受力与消散”的单次过程。空间允许时使前沿横跨需要受影响的人物区域，传播方向由建筑锚点与人物实际位置决定，不只写“朝镜头冲来”。不能一面写在远处，一面立刻出现在人物胸前。
- 用半透明移动折射带、低反差能量薄层等当前适用的外观描述前沿；颜色、形状与强弱服从项目。只在获准时加被推动的薄尘、发丝和衣料，不默认生成实体墙、火焰、爆炸或多层持续脉冲。用户要贴身力场时明确附着范围与向内/向下的作用，不改成远程气浪。
- 区分视觉折射和实体变形：可让波带经过处的墙柱边线短暂错位，波带离开后恢复；无破坏剧情时，石柱、门框和地砖的实际结构不弯折、搬移或被吸进漩涡。避免整幅人物和建筑持续像软胶一起扭动，不以全屏模糊替代局部折射。
- 写清察觉与受力顺序。若要求先看源头再抵挡，源头变化先触发转头，前沿到达时才让身体后压、手臂承力和衣料偏移；预见袭击时可提前抬臂准备，但接触后的震动不能提前发生。多人按实际远近和姿态响应，不机械同步，也不为错开反应改站位。呻吟、重呼吸保留人物差异，不自动变成同声喊叫。
- 摄影机受冲击的晃动只在当前要求或既定拍法允许时加入，绑定前沿到达的节点并收稳；它不能代替人物受力，也不让场景结构换位。用户取消晃动、改硬切或取消音效时，同步删去旧运镜、触发声与公共尾注的相反要求。

### 瞬移与时间状态

- 瞬移写清消失起点、目标空地、出现后的朝向、手别、持物与支撑。需要穿行空间时按既定布局避开人物与障碍；不把瞬移改成连续奔跑，也不把主动瞬移误判成无依据换位。
- 瞬移拖影是短暂的半透明运动残留。说明拖影指向落点、如何消散、最后只保留一个实体；不生成能独立行动的分身。普通背景虚化不写成人形拖影或额外特效。
- 将发动、途中与抵达分别标明当前阶段。跨镜展示瞬移途中时，区分故事中的短暂位移与观众看到的慢放或主观展示；主观慢放描述时间感受，不自动改成第一人称POV，实际视角仍服从既定机位。需要看清途中身体或武器时，说明可见的是同一主体的过程表现，避免“全程无可见实体”与“途中清楚看见实体”并存。没有明确的完成条件，不在前镜提前写出终点凝实、落稳或到达后的支撑动作；已明确回放或非线性剪辑时按其意图处理。
- 时间静止先按当前意图区分完全静止、局部静止和极慢动作，再确定受影响对象、允许活动者及其携带物和相关效果。摄影机可运动时，静止的场景仍因观看位置变化产生真实视差及适用的运动模糊；这是相机相对运动，不是环境自行运动，不用整段视频定帧代替世界静止。
- 例如环境已冻结、施法者与其黑气可动时，瞬移与黑气可继续，环境火焰、尘粒及其他人物按已定规则不动；不额外用落脚气浪吹动被冻结的尘土。解锁前后只切换一次，不在相邻镜头提前恢复动作。
- 给锁止与恢复分别指定唯一动作触发点，核对接触、受力位移和声音发生在触发前还是后。被冻结对象能否被外力推动须服从已定规则；不能一面要求完全不可动，一面在恢复前安排反应。允许接触时解锁等不同设计，不把某一项目的解锁时机设为通用默认。
- 同一效果有退出条件，残留痕迹另行延续：烟雾散尽不等于墙痕消失，临时神力不等于原有伤势自动痊愈，变身不等于相邻家具尺寸改变。
- 局部镜头新增效果发射部位或改变恢复触发时，同步核对公共效果来源及声音事件次序。区分接触前的触发声、接触声和之后的结果声，不把“同一段内发生”无依据写成全部严格同步；也不把合理的同一动作声层叠加判成重复事件。

## 五、设计声画关系而不强加配乐

- 仅在任务允许声音时补适配音效，明确来源和触发：积蓄、释放、命中、余响分别对应动作，音量与距离服从同一空间，避免一次命中出现两次独立撞击。
- 低频嗡鸣、气流、机械或能量声属于适用的效果声，不自动形成旋律、鼓点或背景音乐；用户要求静音或无某类音效时优先遵守。
- 含神谕或咒语时，先区分实际开口、OS与VO。已给原句完整说一次，适用叠层紧密同步，保证口型、字词和主声清晰，不额外增加多次吟唱或笑声。
- 台词跨切镜时，前镜在未完成处切出，后镜只接同一次发声的余句或尾音；不能前镜说完又在后镜重新起句。角色原有音色、表演语气与共鸣/混响分开指定，神力感不自动变成另一个人的声线。
- 参考音频或视频未能查看时，不声称已分析其具体音色、节拍或效果，先按已明确描述完成能做的部分。
- 把变身音效的节奏参照转成听得见的过程，例如低沉心跳间隔逐渐缩短，旋转气流持续收拢，完成点落下一次干脆、宽频的炸响并接短余响。心跳、旋涡风声与最终冲击是不同声层；用户只要节奏感时，不搬入参考作品的唱名、台词、配乐或未要求的金属启动声。
- 区分旋转气流与液体咕噜、短促炸响与气泡破裂。用户已指出误读时，以正向声学特征限定目标，再用必要短句排除误读，不堆叠连续爆响。无BGM不等于没有心跳节奏或效果声，用户明确不要节拍时再取消。
- 钟表或齿轮声按当前要求写转动、变慢、锁止与恢复等实际阶段，不额外生成实体时钟。声音是否可用与剧情是否保留时间规则分别处理；只取消音效不自动取消视觉规则，明确取消该剧情阶段时同步删除其声音和依赖动作。

## 六、局部编辑与满屏转场

### 只改已有视频中的特效

- 把实际待编辑视频定义为唯一母版，写明目标人物/物件、部位、作用时段或全片范围及需要改变的外观；不重新套剧情生成稿，不借局部修改改变机位、表情或时间顺序。视频无法查看时说明未核验，不猜原始眼色或光源。
- 区分自发光、角膜反光、金属反射和场景照明。“眼睛正常”可写成恢复与母版正常阶段或指定人物资产一致的虹膜、瞳孔和眼白；保持原眼形、视线与眨眼，只移除指定眼部自发光、光晕及其造成的局部溢光。保留合理角膜反光，不把眼睛抹成无反射黑洞。
- 精确约束颜色作用域：只去眼部金光，不取消同色护身符、金属饰件、火光和其他已定金色效果；不擅自改成黑瞳、黑雾或另一种发光颜色。非眼部编辑迁移同一范围方法，不套用眼球术语。
- 除指定对象和不可分的局部光照依赖外，保留母版的人物身份、五官、动作、伤痕、道具、背景、光线、构图、镜头、剪辑与原声。只改画面时不重做音轨，只改音效时不重做画面；不保证局部生成能逐像素保持原片。

### 金光、暗场与末态覆盖

- 区分实体再次出现、体内余能发亮与单纯镜头过曝。护身符已融入身体时，胸前再次亮起的是余能，不能无依据在掌心重新生成一枚护身符。先读真实首帧/尾帧，承接空掌、姿态、伤势及尚未消退的效果。
- 用户要“疑惑看光→光铺满画面”时，先在未遮脸阶段看清目光下移和疑惑，再让胸前/体内的光增强，亮区向外扩展至画面四边，最后人物和背景轮廓被金光完全覆盖。满屏包括四边与边角，不是胸前一个亮球或只在身体周围绕光。
- 明确结束保持的对象：若要转场用的全屏金色，末态只剩稳定的明亮金色光场，不再显出人物；不额外生成下一场景、闪回或重复吸收。用户只要扩散且仍见人物时保留该结尾，不能一概铺屏。
- 清理冲突的公共约束。“始终看清面部、特效永不遮挡、全片禁止增亮/过曝”只可限定在反应可读阶段，不能同时约束满屏覆盖末态。真实材质与连续光照仍适用于覆盖之前，不用纯色插帧冒充有来源的扩展过程。
- 黑场隐藏按实际可见范围处理：只允许一对发光眼睛可见时，其余面部、衣服、门墙与地面应降入不可辨暗部，而不是只加黑雾。把建筑眼窝逐步匹配成人物眼距时锁定数量、位置、距离变化与人物揭示时点，不让建筑骷髅无依据变成人。仅在当前剧情要求这种转换时使用。
- “保持亮场”“后期切黑”“本段直接转场”分别处理。用户后期自行切黑时，不在生成片段末尾追加自动熄灯、淡黑或空景；用户要片尾金色保持时，不套用无关的后期黑屏方案。

## 七、可迁移短例与出稿检查

下例只说明方法，不把匕首、骷髅、蓝红黑顺序、紫色符文或黑烟设成其他故事的默认值：

> 三次切回刀鞘时，骷髅眼窝依次只呈现蓝、红、熄光后的深黑；少量烟从固定嘴部齿缝逸出。刀根露出后，刀身黑烟持续来自紫色符文及护手附近，随新露出的刀身蔓延；完全拔出后进入刀刃与右手的环绕阶段。骷髅与空刀鞘仍在后腰，眼角薄雾不移到刀身。快切接续同一次出鞘，不重启变色或重复拔刀。

| 原意或反馈 | 可迁移写法 |
|---|---|
| “威压像一道圈，人物没有承受压力” | 核对贴身压制还是远处气浪；明确作用方向、到达时点及获准的身体张力，不只加粗颜色或增大光圈。 |
| “参考某作品的空间扭曲” | 分解来源、局部折射轮廓、推进方向、经过后的恢复与人物响应；未看参考时不声称复现其具体镜头。 |
| “只去眼睛金光，正常就行” | 锁定唯一母版和目标眼部，保留眼结构、角膜反光、其他金色道具与原声，不扩成全片去金色。 |
| “吸收后体内又亮起，疑惑，再满屏金光” | 继承已吸收状态，不重生实体；先完成可读反应，再扩至四边覆盖，明确亮场末态，移除相反尾注。 |
| “要旋涡声、心跳节奏，最后炸响” | 旋转气流与低频脉冲逐步收拢，完成点一次炸响；不偷加金属唱名或变成水泡咕噜。 |

出稿前检查：

1. 已看清素材所属部件及状态，原始 @资产名与同一物件数量正确。
2. 来源、形状、顺序、动作进度和结束条件没有互相矛盾。
3. 本镜必须看清的部位实际可读，镜头容量允许，布局与环境光没有被特效重置。
4. 前镜末态与后镜首态、画外进度及声音接续，无重复起效或命中。
5. 瞬移拖影、环境柔焦、时间静止及其例外分得清楚，退出后的既有伤势或痕迹持续。
6. 抽象效果有必要的可见证据，传播、察觉、准备和受力先后成立；视觉折射没有无意变成实体损毁，摄影机震动没有替代作用过程。
7. 局部编辑有唯一母版、目标范围与保留项；自发光与正常反光分开，其他同色物件和原声没有被误删。
8. 满屏或暗场结尾兑现四边、可见内容与保持条件；没有与旧尾注冲突，没有重复生成已吸收的实体或提前揭示隐藏人物。
9. 反馈、抽帧可见事实、听辨过的声音与设计推断分别记录。未重验旧片不冒充本轮已验证，文字试用不等于视频生成成功。
10. 只交付当前任务需要的描述，保持精简，不为每镜追加通用清单，不承诺模型执行或内容审核结果。
