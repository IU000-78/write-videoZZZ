# 镜头、运镜与剪辑选择库

本库包含主流基础、常见细分、进阶与组合选项。行业命名有别名、交叉和持续变化，没有一个封闭的“市面全部运镜”标准。遇到新叫法继续按实际可见运动归类，可检索扩充，不把当前列表当作唯一允许的做法。

## 使用方式与依据标记

- 何时提问、何时提供3个候选及何时出稿，统一按[任务分流与运镜选择](question-flow.md)执行。本库只提供技术与写法，不能用术语菜单替代意图沟通，也不把纯审核或无关局部替换拉进运镜选择。
- 候选展示前先按[故事构图](composition-story.md)检查锁定首帧、人数、空间、轴线、关键可见细节与一镜到底限制。只展示真正适配的方案；机位位移、原地摇摄、变焦、转焦及剪辑分别说明，不能用三个同义名称或违规方案凑数。镜号默认不加秒数，不追加时长询问。
- 在实现层先选镜头组织，再选镜内运动；按需补充光学/焦点、稳定方式、视角景别和时间效果。每镜通常有一个主要运动，复杂段落按动作阶段连接，不同时堆满互斥运动。
- 一镜到底的路线、动作取景、画外对白与旁听反应，按[长镜设计参考](continuous-take-performance.md)落实；不把独立机位直接串成无过渡切换，也不将示例中的固定焦段当作所有长镜的要求。
- `O`：Seedance 2.5官方资料明确出现过该术语或示例形式，来源见[检索依据](camera-sources.md)；不代表该条中文例句已实测或保证生成成功。
- `D`：依据摄影、剪辑定义自行组织的可见描述；尚未逐项验证SD2.5执行效果，不称“官方支持清单”。
- `C`：复杂组合、极端运动或时间/空间效果；补充路径、几何关系与阶段，必要时建议参考素材。可与O并列，说明官方出现过名称但具体方案仍需展开。
- 下表的“写成可见画面”是写法骨架，生成时替换成当前@角色、场景锚点、景别、光源与结束姿态。数字角度只是可选路径描述，不是模型接口参数；默认不写秒数。
- 景别、视角、机位移动、变焦、对焦、稳定方式、剪辑、时间效果各有用途。移动机位改变透视，固定机位变焦改变视角范围，拉焦改变清晰层；用明确文字区分它们。

| S05 | 隐藏切点／伪一镜到底 | 在完全遮挡、暗部或甩动模糊中连接两个段落；两端方向与速度匹配 | C |
| S06 | 正反打覆盖 | 先确定双方位置，同侧轴线内交替呈现说话者与倾听者 | D |

|---|---|---|---|
| M01 | 固定／locked-off／static | 摄影机位置与朝向稳定，主体在画内行动；是否绝对静止按用户选择 | D |

| M13 | 背后跟拍／follow shot | 摄影机从@角色后方沿同一路线跟进，说明间距与转弯处 | O |
| M14 | 正面迎拍／倒退跟拍／leading shot | 摄影机在主体前方后退，面向主体，结束于指定位置和景别 | D |
| M15 | 侧向平行跟拍／side tracking | 摄影机与主体同向移动，维持侧面关系，背景连续掠过 | O |
| M16 | 超越跟拍／overtaking | 从主体侧后方移动至侧前方并放慢，明确穿过哪段开放空间 | C |
| M17 | 局部弧线环绕／arc／orbit | 摄影机沿主体一侧弧线移动，从正前侧到侧面，说明半径与终点 | O |
| M18 | 半圈环绕 | 沿可读弧线从正面到背面；连续呈现跨轴路径，光源与建筑位置稳定 | C |
| M19 | 整圈环绕／360° orbit | 摄影机围主体走完一圈回到起始方向，背景顺序连续，主体不自转 | C |
| M20 | 摇臂／吊臂升起／crane or boom up | 机位沿上升弧线越过前景，逐渐展开主体后方空间，写明朝向 | D |
| M21 | 摇臂／吊臂下降／crane down | 从高位场景构图下降靠近主体，逐步落至指定中景 | D |
| M22 | 遮挡揭示／reveal | 摄影机横移或推进离开前景石柱，露出其后人物；说明遮挡物和路径 | D |
| M23 | 原地摇摄跟随／pan-follow | 摄影机原地转向跟住横向移动的主体，不伴随横移 | D |
| M24 | 甩镜／鞭摇／whip pan／swish pan | 快速转向形成短暂方向性模糊，再停稳在明确目标；默认是同一空间内转向 | D |
| M25 | 快速上甩／下甩／whip tilt | 快速俯仰从一个高度转到另一目标，停稳后恢复可读构图 | D |
| M26 | 滚转／roll | 摄影机绕镜头光轴旋转，画面地平线逐渐倾斜，说明方向与结束角度 | D |
| M27 | 整圈滚转／barrel roll／盗梦式旋转 | 镜头光轴朝向主体，画面绕中心旋转一周；不等同绕主体走一圈 | C |
| M28 | 低机位贴地跟移 | 镜头保持地面上方的低位，沿脚步或车轮路径平行前行 | D |
| M29 | 顶视平移／overhead tracking | 镜头垂直向下，机位在主体上方沿路线移动，保持顶视关系 | D |
| M30 | 航拍掠过／flyover | 高位机位越过指定地标，沿路线从近处地形进入远处目标 | D |
| M31 | 航拍后拉升高／dronie | 从主体上方近处后退并升高，人物缩小，周边地貌逐步展开 | C |
| M32 | 俯冲／dive | 从高处沿明确斜线向低处目标接近，接近终点时减速并重新构图 | O/C |
| M33 | FPV穿越／fly-through | 第一人称飞行沿指定通道穿过可容纳摄影机的开口，写清入口、转向、出口 | O/C |
| M34 | 螺旋升降 | 绕同一中心运动并逐步改变高度，明确旋向、半径、终点 | C |
| M35 | 弧线推进／弧线后撤 | 靠近或远离主体的同时小幅绕行，按阶段交代距离与侧面关系 | C |
| M36 | 运动交接主体／handoff | 先跟随@角色甲，到两人交会处转向@角色乙，再沿乙的路线继续 | C |

## L：变焦、对焦与镜头光学效果

| 编号 | 名称／别名 | 写成可见画面 | 依据 |
|---|---|---|---|
| L01 | 缓慢变焦放大／zoom in | 机位固定，焦距逐渐变长，主体在画面中放大；不出现前后移动视差 | D |
| L02 | 缓慢变焦缩小／zoom out | 机位固定，焦距逐渐变短，视野扩大，露出周边画面 | D |
| L03 | 急推变焦／crash or snap zoom in | 机位不前冲，以快速变焦从中景收至表情或物件近景 | D |
| L04 | 急拉变焦／snap zoom out | 机位不后撤，以快速变焦展开环境，停在明确构图 | D |
| L05 | 希区柯克变焦／眩晕镜头／dolly zoom／contra zoom | 摄影机后退同时变焦放大，或推进同时变焦缩小；主体大小大致稳定，背景透视关系变化 | O/C |
| L06 | 转焦／移焦／rack focus | 构图保持，焦点从清晰前景移到后景人物；前景逐渐虚化，后景清晰 | O |
| L07 | 连续跟焦／focus pull | 主体靠近或远离时持续调整焦点，始终保持主体眼部清晰 | D |
| L08 | 深焦／deep focus | 当前构图中前中后景均有可读细节，动作在不同纵深层发生 | D |
| L09 | 浅焦／浅景深／shallow focus | 主体双眼清晰，前景与背景柔和虚化；不额外移动焦点 | D |
| L10 | 虚焦到清晰／focus reveal | 同一主体从失焦轮廓逐渐变清晰，机位与主体形状保持 | D |
| L11 | 分区屈光镜效果／split diopter | 前景一侧与远处另一侧同时清晰，中间保留合理的焦区过渡 | C |
| L12 | 移轴选择焦点／tilt-shift look | 画面只有指定窄区域清晰，其余逐渐虚化；说明是否需要微缩模型观感 | C |

## E：剪辑、连接与转场

剪辑与运动可以组合；转场必须写前一画面、触发节点、连接方式和后一画面。默认使用动作或台词节点，不加秒数。

| 编号 | 名称／别名 | 写成可见画面 | 依据 |
|---|---|---|---|
| E01 | 硬切／直接切／straight cut | 前镜结束后直接出现下一机位，不做中间溶解 | D |
| E02 | 动作衔接切／cut on action | 在同一动作进行中切换角度，下一镜承接原动作，不重复完成 | D |
| E03 | 反应切 | 动作或台词发生后切到接收者的具体反应 | D |
| E04 | 视线匹配切 | 先交代观看方向，再切被观看对象，方向与高度匹配 | D |
| E05 | 插入细节／insert | 在当前动作中切出手、物件或接触细节，再衔接后续动作 | D |
| E06 | 切出／cutaway | 暂时切到相关环境或旁观反应，再回主动作线 | D |
| E07 | 图形匹配／graphic match cut | 两镜以明确形状、构图或色块对应连接，写清匹配元素 | D |
| E08 | 动势匹配／motion match cut | 以相似运动方向或动作阶段连接不同画面，说明时空是否变化 | D |
| E09 | 同轴切近／axial cut／punch-in cut | 沿同一观察轴直接换成更近或更远的构图，属于剪辑切换 | D |
| E10 | 跳切／jump cut | 同一视角有意略过部分过程，主体位置产生可识别时间跳跃 | D |
| E11 | 冲击切／smash cut | 从一个明确状态突然切到强烈反差画面，以事件变化建立冲击 | D |
| E12 | 交叉剪辑／cross-cutting | 在两条相关事件之间交替切换，给每条线清楚的地点锚点 | D |
| E13 | 平行剪辑／parallel editing | 交替表现对应或对照的叙事线，明确是否同时发生 | D |
| E14 | 蒙太奇段落 | 按多个阶段组织短镜头，说明省略过程和保留的因果节点 | D |
| E15 | J-cut／声音先入 | 下一镜声源先被听见，随后画面切到该声源或其所在空间 | D |
| E16 | L-cut／声音延续 | 画面已切换，上一镜对白或环境声继续覆盖下一镜一段动作 | D |
| E17 | 叠化／溶解／dissolve | 前镜逐渐淡出时后镜逐渐出现，说明两者各自内容 | D |
| E18 | 淡入／淡出／淡至黑 | 从黑场显现画面，或让当前画面逐渐归黑，指明接续方式 | D |
| E19 | 淡至白／白闪连接 | 以明确光源、闪光或白场覆盖进入下一画面，说明是否保留事件连续 | D |
| E20 | 划像／wipe | 新画面沿指定方向替换旧画面，属于可见转场效果 | D |
| E21 | 遮挡转场／mask wipe | 指定前景物体覆盖画面后连接下一段，露出时构图和方向明确 | C |
| E22 | 甩镜匹配转场／whip-pan transition | 前镜甩向某方向，在模糊处切到同向运动的后镜；与单镜甩动区分 | C |
| E23 | 变焦匹配转场／zoom transition | 指定中心目标与缩放方向，在放大/模糊处连接下一构图 | C |
| E24 | 形变连接／morph transition | 明确A对象如何逐步变成B对象及最终状态，仅在需要变形时采用 | C |

## T：时间与运动速度效果

| 编号 | 名称／别名 | 写成可见画面 | 依据 |
|---|---|---|---|
| T01 | 慢动作／slow motion | 指定动作阶段放缓，保持受力、重力与人物身份连续 | D |
| T02 | 快动作／fast motion | 指定过程加速，保留足以读懂的关键动作，不凭空增加次数 | D |
| T03 | 变速／速度坡度／speed ramp | 在指定动作节点由正常变慢，再平滑恢复，说明摄影机是否同时变化 | O/C |
| T04 | 固定延时／time-lapse | 机位稳定，云、人流或光线呈现明显时间压缩 | D |
| T05 | 移动延时／hyperlapse | 机位沿路线前进，同时压缩较长时间，保留建筑锚点 | C |
| T06 | 子弹时间／bullet time | 事件几乎凝住，摄影机沿明确弧线观察同一瞬间，再恢复动作 | O/C |
| T07 | 定格／freeze frame | 画面停在指定动作状态；如仍需绕行观察，另写T06的空间变化 | D |

## 将选择落到提示词

每镜以“当前@主体与@场景＋起始景别/机位＋唯一主要路径或按序运动阶段＋速度/触发事件＋焦点/光线保持＋结束构图”组织。不用术语取代画面，不把库编号当作SD2.5参数。

可组合骨架：

- S01＋M14＋M22：前方倒退迎拍，经过门口前景遮挡后继续同一条通路；单镜不插入切换。
- S03＋M01/M03＋E02：中景交代动作，在接触前切到细节，承接同一次动作，随后切反应。
- S06＋V08＋L09：同侧轴线过肩正反打，明确当前说话者和倾听者，浅景深背景虚化。
- M17＋L06：沿主体一侧小弧线移动，在停稳后把焦点由前景物件转到主体眼睛；把两阶段写清。
- M31＋V04：从人物上方后拉升高，镜头逐步转为顶视，清楚说明角度改变，不同时声称朝向恒定。
- S05＋E22：甩动模糊中隐藏切换，后段承接同向运动；标明这是长镜效果，保留剪辑事实。
