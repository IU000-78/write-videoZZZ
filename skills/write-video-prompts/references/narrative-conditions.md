# 叙事前提、角色察觉状态与隐藏条件

处理发现、躲避、藏匿、偷听、跟踪、误认、隐瞒及延迟揭示时使用。先按[任务分流](question-flow.md)决定本轮交付，不另设问卷；单镜、审核与局部修改只检查相关角色和依赖。以下方法与案例为基于剧情和已查看画面的归纳，不是视频模型执行能力保证。

## 一、先判断事件成立的前提

在拆镜和选运镜前，提取关键事件、必要前提、触发事件与结束结果。例如“发现来人后躲藏”需要区分“已被撞见后逃开”和“在被发现前藏好”；不能仅把每句舞台说明依次拍成全景。

- 分开记录观众知道什么、各角色分别知道什么，以及真实空间允许他们看见或听见什么。观众看到了危险，不代表所有角色都已察觉。
- 将察觉关系按方向记录：@甲察觉@乙，不能自动推出@乙也察觉@甲。区分看见有人、听见声音、认出身份、怀疑有人与确信对方在场；未交代时保留未知，不替剧本补成已知。
- 依据用户明确说明锁定前提；只从动作推断时标明推断。原文确有决定性歧义，才在原有最多三个意图问题中优先补问，不新增一轮通用确认。
- 用户已明确“未被发现”“观众暂不知身份”或“这次就是被撞见”时直接继承，不重复询问，不把某个反例变成所有场景的默认结局。
- 保留明确的行动先后。调整呈现顺序与摄影方式，不能悄悄把“推同伴进入后自己进入”改成“自己先走、同伴随后跟进”。

## 二、在逐镜状态中加入察觉关系

内部按需要记录以下字段，不强迫用户填表，也不在每镜堆放分析术语：

| 字段 | 要记录的内容 |
|---|---|
| 必须成立的前提 | 谁需要未被察觉、谁已认出谁，哪些信息只对观众开放 |
| 有方向的角色状态 | 观察者、目标、已察觉/怀疑/未察觉/未知；需要区分时另记身份是否被认出 |
| 状态变化的依据 | 看到、听到、转头、被指认等具体事件；无触发就不自动同步知情 |
| 真实视听条件 | 位置、朝向、视线遮挡、注意力、声源与距离；未验证条件保留为条件 |
| 同框限制 | 本段允许同框的人物组合、明确禁止组合，以及限制持续到哪个事件 |
| 时间与行动顺序 | 危险对象持续从哪接近；谁先行动、谁后通过；何时遮蔽、关门或被发现 |

逐对核对上一镜末态与下一镜首态，知情变化同样需要依据。切镜、转焦、移出画框和背景柔焦本身均不改变角色的真实位置、视线或听觉。

## 三、分别检查画框与故事中的视听条件

- **对观众隐藏**：检查取景范围、焦点、遮挡和揭示顺序。
- 延迟出场时，另按[暗场与揭示状态](reference-state-gates.md)区分真实在场与画内可见；隐藏的人物仍在固定位置，不能用全局人数限制排除他。把可读区域与隐藏区域分开，灯光或镜头变化只揭示原状态，不把清楚的空座位当作有人被黑暗遮住。
- **对某角色隐藏**：从该角色实际位置检查他能看见、听见什么，以及注意力如何分配；不能以摄影机没拍到目标作为隐藏依据。
- 用户明确禁止两组同框时，按任意跨组成员组合执行，不是只禁止两组所有人同时齐全。逐镜限定画内人物，并检查背景、过肩、倒影和运镜途中是否带入另一组。清楚的影子或声音会泄露在场信息时也要检查，不把禁同框扩大成禁止一切环境影子与声音。
- 同框不自动等于互相发现。其他剧情有真实遮挡、相反朝向或可信注意力依据时可以成立；当前片段的明确禁同框要求仍须执行。
- 分开拍摄与POV只解决观看组织，仍需真实视线或时机支持。POV朝向来人时检查对方眼线，不能同时把“未发现”写成“朝观察者直视并确认身份”。
- 使用已有门框、墙体和地形时保留其真实位置；不能为了隐藏人物凭空增设转角、屏风、家具或改变锁定路线。长焦压缩、浅景深、特写和切镜也不能代替实体遮挡。
- 没有实体遮挡时，只在剧情支持的距离、朝向、注意力与行动时机内设计。不要用“对方看不见”“绝不会发现”掩盖条件不足；锁定条件确实冲突时明确指出必要取舍，审核结论不因此暂扣。

## 四、让行动赶在前提被破坏之前

- 躲藏可按“察觉危险→发起动作→同伴通过→自己通过→完成遮蔽/关门→危险对象接近该处”校核；具体先后以本剧本为准，不能机械套用这个例子。
- 检查门扇开合、通道容量、推人方向和双方距离是否给行动留下空间。危险对象继续按原路线运动，不因切到主角就无依据停在远处。
- 记录需要完成的条件，例如门已合拢且两人已在室内，然后才允许下一镜的来人进入对应位置。按必要精度写距离和动作阶段，不因检查先后而自动加入秒数。
- 声音也可能改变察觉状态。开门、碰撞、呼喊和关门声要符合现场距离与声场；可设计合乎动作的轻合，不用凭空静音或强加爆响破坏“未被察觉”。
- 一镜到底、固定景别和已锁定路径继续有效。在这些限制内设计连续遮挡与揭示，不能偷加硬切；客观不兼容时按任务流程指出具体冲突。

## 五、在候选方案与出稿前执行检查

每种导演组织、呈现给用户的三种运镜方案及最终稿，都先核对：

1. 当前哪些角色已经知道什么？是否有人无依据提前反应或突然失去已知信息？
2. 观众所见与各角色所见是否被区分？已确认的隐藏前提有可见或可推断的依据吗？
3. 本段禁同框组合是否在开头、运动中途、关键动作和末态都没有被带入？
4. 从危险对象的位置看，人物是否已暴露？声音是否会触发察觉？分开拍摄是否仍掩盖不了空间矛盾？
5. 行动、进门与关门是否在相应条件改变前完成？相邻镜头是否维持距离、人数和动作先后？

发现违规时，在授权范围内先调整调度、切点、机位或合乎剧情的时机，不把明知违背前提的方案留给用户选择。表达意图不明确才补问决定性信息，不重新索要优化许可。成稿写实际位置、朝向、声源、动作与结束状态，不只写“保持未被发现”。

## 六、案例：地下拍卖场走廊躲藏

依据已查看的《反面案例-1.mp4》关键画面及用户提供的剧情归纳，只保存文字经验，不依赖技能外的视频路径。用户明确本段是@玛卡里亚发现来人，路人未发现两位主角，并要求主角组与路人组不同框。

- 可见问题：前景主角仍交谈时，后方来人已经入画并沿同一走廊接近，女主随后才转头和开门；画面没有建立足够的遮挡、注意力或时机依据支持“未被发现”。同框在本段同时违背用户的明确要求，但不能据此把其他剧情的所有同框都判错。
- 动作问题：成片女主先进入、男主随后跟进，与剧本“先将凯登推进去，自己再进入”的顺序不同，应进入动作状态检查。
- 角色状态：@玛卡里亚已察觉来人；@凯登是否看见来人未被剧本说明，不能擅自写成也已发现；路人仍未察觉主角。主角在画外并不自动满足最后一项。
- 允许切镜时，可组织为“主角画面察觉→女主POV仅见路人→主角组按原顺序进入并关门→路人继续接近”，同时校核现实视线、距离和声音；这不是仅靠分镜就能证明隐藏成立的固定模板。
- 缺少当次完整生成提示词，不能把可见问题确定归因为提示词遗漏或模型未执行。调试时分别检查剧本前提、提示词是否落实、成片是否执行，再定位需要更新的层次。

迁移的是前提、角色知情差异、同框限制与视听条件的校核方法，不迁移本案例的人名、门、固定剪辑顺序或“所有躲藏都禁止同框”。
