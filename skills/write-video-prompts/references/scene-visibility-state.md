# 场景可见范围与变化继承

编写、补镜、审核或修改分镜时自动应用本页，按[任务分流](question-flow.md)保持当前工作范围，不新增提问门槛。逐镜确认“此机位能看见什么、明确不能出现什么、此前变化留下了什么”。这是提示词与构图的检查方法，不是视频模型执行保证。

## 一、分清固定布局、当前状态与画内范围

- 固定布局：场景身份、墙体、入口、柱列、平台、固定家具位置及尺度。依据实际素材或已定文字建立世界坐标，不把每镜的屏幕左右当作世界左右。
- 同一墙面或道具改用特征锚点命名时，在内部保留它与原坐标的对应，例如“受损墙面”仍是既定右墙，而非新增一面墙。正文用当前最清楚的名称，后续损伤、人物贴靠和背景方向继续属于同一对象；不同物件不能只因名字相似就合并。
- 当前状态：某事件之后，哪个具体对象变成什么状态，例如右墙出现三道爪痕、门已合拢、灯已点亮、挂毯缺了一角、家具倒在何处。没有新事件或明确时间变化，不恢复母图的初始状态。
- 画内范围：按当前摄影机位置、朝向、景别、取景边界及真实遮挡，确定本镜必须看清、允许入画和明确禁入的区域。真实存在、能否入画、是否可辨认分别记录。
- 场景一致是同一布局与事件状态在不同视角下成立，不是每镜使用同一张背景。反打按实际朝向呈现对侧空间，不把人物背靠的墙无依据搬到对手身后，也不因背景要相同而更换人物站位。

## 二、为每个画面确定背景边界

内部按需要核对下列信息，不默认向用户输出全表：

| 字段 | 检查内容 |
|---|---|
| 场景与机位 | 当前场景、人物落点、摄影机在哪一侧、朝哪个实际方向拍摄 |
| 可见背景 | 前中后景实际能出现的墙段、柱身、门面或地面，以及需要可读的空间锚点 |
| 禁入范围 | 用户明确不许出现、尚未到揭示时机，或此机位按布局不该看到的区域与物件 |
| 当前变化 | 该可见区域在此前事件后的门窗、光照、损伤、陈设和痕迹状态 |
| 运动过程 | 起幅、移动或转向途中、落幅是否始终符合上述边界与状态 |

- 优先正面写清实际背景和镜头方向，再用必要的短句排除明确禁入项。例如“摄影机位于交互区域纵深一侧，朝右墙斜拍，背景仅为受损右墙局部；远处平台保持画外”。不要只写“禁止出现王座”却仍将机位朝向王座。
- 背景虚化仍可能保留物体轮廓，不替代画外或真实遮挡。用户要求完全不出现时，应检查画幅边缘、过肩、运动途中及实际存在的反射面；不为验收而新增镜子或反光道具。
- 某物不入镜，不等于从世界中删除或移动。画外火盆仍可照亮人物，画外门仍保持当前开合，不能为了禁入而无依据灭灯、拆墙或搬走家具。
- 未明确禁止的背景物件，若从真实机位应当可见，不武断判为穿帮。信息隐藏与作者有意的构图按现有意图处理，不自动强制全景或强制所有角色同框。
- 首帧或绑定素材已把禁入对象清楚放在画内时，先报告素材与要求的实际冲突，按授权调整构图、换用相符素材或说明所需修正；不承诺追加否定词即可覆盖相反的图片信息。具体沿用[素材与揭示检查](reference-state-gates.md)。

## 三、让场景变化传递到所有后续相关镜头

- 为每次改变记录最小事件信息：“何时触发→哪个对象及固定位置→旧状态→新状态→影响哪些后续画面”。不只更新紧邻下一镜，还检查数个特写之后的回拍、POV、反打及下一段续接。
- 门关闭后，后续可见门面按已关闭状态呈现，相关门缝光与通行条件同步改变。保留门缝、完全合拢与门后另有独立光源等不同情况，不一律消除全部亮光。
- 墙面受击后，裂痕、凹陷或爪痕固定在同一面墙、同一区域，数量与尺度按既定事件延续。换角度后透视与遮挡可变，但不能转移到另一面墙、自动修复或无依据增加损伤。
- 烟尘、火花、飞屑等短暂效果按时间逐渐衰减；墙痕、碎片落点、被扯掉的布料或倒置家具等后果持续到清理、修复或其他明确事件。不能因烟尘散去让损伤消失，也不能让大量烟尘在后续所有镜头等量悬停，除非已有时间静止等设定。
- 灯光点亮、熄灭或改变后，后续受光面、阴影、反射及可见范围随固定光源更新。切镜不重新开灯，光源不自动跟随人物；局部变化不把整间房改成另一种布景或统一染色。
- 陈设移动、破损或布料被取走后，保留其新位置、剩余结构和必要接触阴影；后续再使用该物件前核对是否仍可取得，不从未变化的旧图再生一份。
- 隐藏在画外的场景对象仍保存新状态，只有再次实际入画时才呈现必要细节，不为证明连续性强行插镜。真实时间省略、换场或用户明确重置时按该事件更新，不把上一场的禁止项、损伤和天气机械迁移到新场景。

## 四、联动资产与提示词依赖

- 场景资产负责固定结构，当前剧情状态覆盖其初始门窗、灯光、损伤和陈设状态；同时检查图片是否实际冲突，不把文字覆盖当作已经修好素材。布局图不提供最终布景或拍摄视角。
- 用户改动机位、人物落点或某个场景事件后，重查所有受影响镜头的可见背景和后续状态；未受影响的台词、表演与拍法保持原范围，不借一致性审核重写整段故事。
- 将“状态持续”“本镜必须看清”“本镜必须画外”分开。必须看清的痕迹要有合适角度、尺度和清晰度，不能用全背景虚化掩盖；只需持续的痕迹不强塞进人物特写。具体配合[故事构图](composition-story.md)。
- 正文尽量用一两句写当前机位的背景及相关变化；公共设定承载全段限制，各镜只补差异，不每镜复制完整房间、全部损伤和冗长否定词。局部修改只改请求项及必要依赖，按[任务分流](question-flow.md)默认返回当前稿的完整提示词；仅本次明确要求替换段或原任务只有单镜时局部交付，纯审核不自动改写。

## 五、可迁移例子与出稿检查

例子只说明方法，不将王座、右墙或三道爪痕作为其他项目的默认布景：

> 本段不拍远处王座：将关系镜头安排在交互区域纵深侧，朝侧墙取景，并检查横摇途中。女主身后右墙已出现三道爪痕：后续同一墙段实际入画时保留爪痕，烟尘逐渐散去；切到从女主一侧看反派的面部特写时，背景按真实朝向呈现室内通道，不将她背后的墙复制到反派身后。

出稿前逐镜核对：

1. 首态、运动途中和末态的机位朝向、取景边界与真实布局相容，明确禁入项没有因柔焦或切镜而偷入画。
2. 每个已发生变化的对象都有位置与当前状态，后续所有实际涉及它的画面继承新状态。
3. 暂时效果、持续痕迹及退出或恢复条件分清楚，灯光和通行等依赖同步更新。
4. 画外不等于不存在，换视角不等于换位置，旧资产不重置事件，不为避开背景而添加无依据的实体遮挡。
5. 不把场景一致误写成固定背景贴图，不越过用户的局部修改范围，也不声称文字检查已验证成片无误。

依据：用户的场景与损伤连续性迭代经验，以及[Adobe 连续性剪辑](https://www.adobe.com/creativecloud/video/hub/ideas/what-is-continuity-editing-in-film.html)关于跨镜空间关系和动作衔接的一般原则；本页的逐镜背景与事件继承流程为综合写法。
