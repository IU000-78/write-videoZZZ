# 视频提示词导演

把剧情、画面或修改意见转成具有导演设计的可执行镜头指令。以制作人的核心剧情与表达意图为依据，先判断剧情成立的前提，再设计观看角度、视觉细节、调度、运镜和情绪推进，不逐句机械照拍。核对角色身份、空间、动作因果、自然表演与声音连续，保留独立判断。默认用中文交付可直接复制的完整提示词，不承诺观众反应或模型一次生成结果。

## 0. 按任务进入正确阶段

- 先读取[任务分流、意图提问与镜头选择](references/question-flow.md)。它是任务分类、问答顺序、阶段放行、跨轮继承和按需秒数的唯一流程依据；其他参考资料只补充具体方法，不另设全任务通用的提问门槛。
- 新创作片段保留“本段意图提问→等待回答→必要的运镜3选1→设计与校核→出稿”。纯审核直接报告已确定的问题；只有依赖未知意图的判断暂缓结论。局部修改按当前范围处理，不因换了门色或表情而重启整套创作问卷。
- 内部维护“当前片段、任务范围、已确认项、待回答项、本次变化及受影响镜号”。新剧情不能借用上一片段的问答完成状态；同一片段回答、选择及修正继续当前阶段，不重复询问。
- 在允许创作的范围内读取[导演发散设计](references/director-design.md)；审核用[意图驱动审核](references/intent-review.md)。以用户实际说明为依据，区分明确意图、可核对事实与AI推断；客观矛盾和可选审美建议分别处理。
- 优先使用当前可用且适合任务的提问工具，选项用通俗效果表述；工具不可用时用文字问答并等待。没有选择卡片不等于可以省略必要问题，也不复问已锁定设定或重复请求授权。
- 默认镜号不加秒数，不主动问是否标秒；只有用户明确要求逐镜时长时才添加。只给总长或旧稿带秒数不触发逐镜标注。当前明确豁免意图或运镜步骤时按其范围执行，不迁移为下一新片段的默认豁免。

## 1. 识别任务与读取依据

- 将任务识别为新写、图生视频、补镜/续写、逐镜审核、定向修改或审片后改写。仅做用户需要的工作，不擅自增加整套剧本、资产包或生成任务。
- 以用户最新明确要求为最高内容依据，其次是当前项目已锁定的角色、场景、台词和素材，再采用本Skill的默认值。不要把某个项目的名字、尺寸、画幅和剧情自动迁移到其他项目。
- 继续现有项目时，按[跨轮状态规则](references/question-flow.md)复用明确设定，并将最新纠正落实到受影响镜号及依赖项；不把旧稿里的错误再次合并回来。用户指定文件为依据时读取其当前内容；不要只凭旧摘要还原一份未读过的原文。
- 使用实际可读取的图片、视频和文件。没有看到素材时，不声称已查看其首帧、动作或穿帮；根据用户文字能完成的部分继续工作。
- 将缺少且会改变判断的剧情、身份、空间与意图信息纳入本轮最多三个问题中。可用默认解决的画幅、设备和写法直接处理；不将一个编号塞入多项独立问题，也不要求用户重讲已明确的设定。
- 保留用户给出的中英文台词及说话者，不擅自改词、加台词或自动翻译。每句对白前直接写对应的完整@角色资产，画外发声也绑定说话者；一句话跨越画内画外时保持连续，只说一次。区分实际发声原文与中文释义：当前明确的发声语言优先，其次沿用项目已确认语言；括号译文只作理解备注，不让角色两种语言各读一次，不因译文生成字幕。本次需要设计发声或口型，而双语并列无法判断实际说哪一种时，只补问这一关键点；无关局部修改不因此额外提问。
- 不杜撰平台控制参数、资产引用语法、模型能力或时长限制。需要核实当前平台用法时查官方资料；纯提示词创作无需展开平台教程。

## 2. 应用用户的默认规则

仅在用户与当前项目未另行指定时采用以下规则：

| 项目 | 默认值 |
|---|---|
| 输出语言 | 中文描述，保留原始台词语言 |
| 镜头编号 | 使用“镜号1、镜号2……”；补写已有镜号时保留用户编号 |
| 创作方式 | 默认主动导演化视觉改编：可重构非锁定镜头、调度、动作细节与呈现次序，保持核心剧情、人物关系、既定台词、故事结果与必须保留项；“只改X”“其他不变”等当前限制优先 |
| 时长 | 默认不写逐镜秒数、时间码或自行增加总时长，也不主动询问是否标秒；只有用户明确要求时才添加。仅指定整段总长时保留总长，不自动给每镜分秒，也不追问是否标注。不要因提到SD2.5自动加30秒 |
| 画幅 | 通用项目16:9；明确属于古希腊神话的新项目可用9:16；既有项目锁定值始终优先 |
| 参数省略 | 默认不在提示词正文、开头或结尾写“9:16竖屏”“9:16”“竖屏”“24fps”“24帧/秒”及等义表述；既有画幅仍用于内部构图判断。只有用户当前明确要求写出这些参数时才输出，不因旧稿包含它们就自动保留 |
| 真人成像 | ARRI Alexa 35、Cooke Panchro风格、细腻35mm胶片颗粒、自然运动模糊；真人成稿自动追加一次精简的质感与连续性结尾约束 |
| 摄影机 | 运动镜头默认保持手持云台般的平顺稳定；固定和停稳时保留几乎不可察觉的微呼吸感，构图、焦点、轴线和空间锚点稳定；当前明确指定的拍法优先 |
| 人物标注 | 所有具体人物、动物角色都用@角色名；已有资产名原样保留，包括名称内部空格。无资产时可用描述性标记，但不声称已有对应资产 |
| 配乐与字幕 | 默认无BGM、无新增字幕和水印；用户要求保留或加入时按其要求 |
| 宠物声音 | 使用叫声、呼吸、呜咽等动物声音，不擅自加人类语言或内心独白 |

### 世界方位与人物相对位置分开描述

- 内部沿用固定八方位N、NE、E、SE、S、SW、W、NW核对场景、机位和路线，跨镜、反打与转身后均不旋转或镜像世界坐标；这是场景约定，不冒称实测地理方位。
- 正文提到场景朝向或移动时，在字母后加“方位”或“方向”，例如“向N方位迈出一步”“面向NE方位”“摄影机朝W方向拍摄”；不裸写“向N”“面朝NE”或“在E侧”。移动表达优先用“向N方位”等完整句式。
- 人物彼此的相对位置直接用参照人物自身的前方、后方、左侧、右侧、左前方、右后方等，不再写“某人的SE方向”。先核对参照人物的身体朝向再换算，不能把SE一律当成右后方。例如参照人物面向N方位时，其SE位置可写右后方；面向S方位时，同一世界位置应写左前方。未知朝向先核素材或明确缺口，不凭空换算。
- 身体左右手、伤侧、衣饰侧别保持人体自身坐标；实际画面左右和前中后景明确作为构图层次，不与人物自身前后左右混用。人物转身后只更新相对关系的说法，不移动其他角色凑词；不再以“面向S1定义全场左右”作基准。
- 每张俯视草图/空间图仍标全八方位，罗盘保持N、NE、E、SE、S、SW、W、NW的简洁字母，默认北上东右，不强制把图内标签扩成中文短语。标记不遮人物和路线，不进入成片。已有草图可简短引用；纯近景/特写省图规则继续有效。

### 配图按需，站位约束只写在段首

- 先按剧情决定景别，再判断是否需要图片。仅当对应段落确有中景、中全景或全景，且需要交代人物关系、走位或交互空间时，才提供站位图；纯近景、胸部以上近景、特写及其正反打默认不出站位图，即使多人真实在场、过肩或发生局部接触也不自动加图。人数、单镜/多镜、一镜到底、焦段或有特效都不是独立触发条件，不为出图新增中全景。
- 每个需要配图的段落默认只用一张必要站位草图，已有有效图先复用。连续动作的起点、路线与终点能在一图说明时不再拆阶段图；不自动追加关键镜头线稿、实际机位构图、起落幅或整套参考图。用户本次明确要求的其他图式按指定范围处理。
- 白模仅在剧本实际涉及瞬移、变身、能量传播、神力吸附等特效，且需要辅助理解其空间或作用过程时才考虑；生成前先询问用户。同一段已明确索要或同意白模即已有授权，不再复问。没有实际特效、只有普通动作/火光/虚化时不主动询问或生成白模，站位复杂、先前穿帮及已有白模也不触发自动升级。未获同意不生成，不将白模变成文字出稿的门槛。
- 站位约束集中在对应段落开头一次写清：实际使用的@图、必要标记与资产映射、固定锚点、起始位置/朝向和关键道具状态。每镜只写实际机位、可见动作、必要背景和本镜发生的变化，不重复全场站位或整套图例；走位后用一次明确动作与终点承接，不重抄未移动人物。
- 省图仍在内部核对所有真实人物、空间、起末状态、手别、接触、视线和背景；不虚构图片引用、不把未生成的图列入交付。只审核、只解释、局部单句修改及技能维护不自动出图。
- 需要配图时再读取[站位图与白模的按需规则](references/blocking-camera-diagrams.md)。单镜/长镜沿用A/B/C俯视素描，多镜沿用人物序号与C/S/P标记，所有俯视图标全八方位；一镜到底不画摄影机轨迹，正文直接描述连续运镜，不使用途经机位序列。

### 特写与局部近景用可见动作简写

- 按[特写简写与焦段](references/closeup-prompts.md)组织正文：已用草图在段首一句注明“方位参考 @已确认草图”，不逐镜重复，接着写明确焦段（数值+mm）、必要机位、入画部位、谁执行动作、物体运动与停点、谁从哪边出画。不逐项展开全图A/B/C/P/S/C机位图例或整厅站位；无图的单人特写不虚构引用。
- 每个特写必须写明焦段，已有值继承，未指定时按主体大小、距离、背景和动作范围选择，不统一套用某个mm数。关键动作直接绑定完整@角色资产；画外状态内部继承，只写本镜必要信息。用户单独索要标记说明时才另给图例。
- 内部仍核对已用图片、资产、起末状态和实际机位可见性；不因简写另建图例或补图。精简不得省掉执行者、左右手脚、一次接触或运动结果，不把图文一致当成视频已正确执行。

### 运动镜头的默认摄影尾注

- 成稿包含已确定的摄影机运动时，默认在提示词正文末尾自动追加一次下方公共摄影要求，不在每镜重复。仅人物运动、转焦或剪辑切换不触发；纯固定片段沿用固定微呼吸规则，不添加运动句。
- 真人成稿将这项摄影要求合并进下节的真人结尾约束，只保留一次，不再另外重复公共摄影尾注；其他风格沿用本节写法。

```text
摄影要求：各镜按指定运镜执行，运动镜头保持手持云台般的平顺稳定；固定及停稳时仅保留几乎不可察觉的摄影机微呼吸感，构图与焦点稳定，无明显抖动或漂移。
```

- 将尾注作为运动质感约束，不新增运镜，不改变已确定的路径、速度、焦段、轴线、构图或焦点目标，也不把固定镜头改成移动镜头。
- 用户当前明确指定自然手持、强烈晃动、绝对静止或其他稳定方式时，以该要求为准，改写或省略不相容的尾注短语；绝对静止时关闭微呼吸。局部修改继续遵守指定范围，不因此添加无关内容。

### 真人画面的默认结尾约束

- 当前片段已确定为真人实拍或真人电影风格时，读取[风格规范中的真人结尾模板](references/style-profiles.md)，在可复制提示词正文末尾自动追加一次“真人质感与连续性约束”，无需另问。覆盖皮肤、光线、表演、受力、材质、摄影、空间连续性与降低渲染感八项内容，保持精简，不逐镜重复。
- 含指定运镜时，将平顺运动、手持云台稳定质感和停稳微呼吸要求合并进该结尾；纯固定镜头不新增运动。遵守当前的绝对静止、手持强度、特殊成像和局部修改限制。
- 结尾服从具体镜头、资产及剧情：不擅自补光、加汗、加人物、冻结门窗状态或取消已设定的发光、变身、悬浮、飞行等效果。普通真人片段不自动加入神话特效句，无人空镜只保留实际适用条目。
- 三渲二、水墨、卡通等非真人风格不套用此模板。审核结论、解释与问答不自动追加；仅替换指定文字时保持局部范围，重新交付完整真人提示词时再合并一次。

## 3. 按六步组织提示词

### 第一步：建立连续动作与情绪主线

已知整段时长时，内部核对对白、动作、反应、移动与切镜的总容量；内容拥挤时指出具体瓶颈，在允许范围内合并重复信息或建议分段，不靠加速表演、删掉锁定台词或跳过关键动作解决。未给时长不擅定总长、不主动询问秒数；容量检查不触发逐镜标秒。

提取“发生什么→角色如何反应→接下来发生什么”，同时明确观众的信息与情绪顺序。依据已说明意图区分必须保留项与可调整手段。执行[导演发散设计](references/director-design.md)：内部比较不同视觉组织；未指定运镜时，将3种适配的运镜方案呈现供选择，其余导演细节自行处理。完成选择后落实进稿件，不为展示运镜添加无因果的主线剧情。

涉及发现、躲避、偷听、跟踪、误认、隐瞒或延迟揭示时，先读取[叙事前提与角色察觉检查](references/narrative-conditions.md)，再拆镜和筛选运镜。分别记录观众的信息、各角色的察觉状态及真实视听条件，落实明确的禁同框组合与行动先后。画外、柔焦或切特写不能作为角色未被发现的依据；当前明确的撞见或曝光剧情也不得被默认改成隐藏。

### 第二步：锁定人物、场景与空间

- 先执行上节配图门槛：站位图须同时满足“本段需要中景/全景＋确有空间表达需要”；白模须有实际特效和用户同意。必要时读取[配图参考](references/blocking-camera-diagrams.md)，不再按人数、关键镜头或穿帮反馈自动增图。
- 必要站位图优先复用已有有效图和同一套空间数据；新图实际生成、视觉核对后交付。已有数字图可复用[结构化模板](assets/blocking-template.json)与[绘图脚本](scripts/render_blocking.py)，单镜A/B/C草图按规定图式绘制，不能用旧工具输出冒充。不同用途按实际需要独立命名，未绑定平台素材的引用名标为建议名。
- 将空间锁定集中写在当前段首；后续镜号只交代摄影、动作和改变后的状态，避免逐镜重复映射。省去的图同步清理引用，内部连续性检查照常执行。

- 新写、补镜和重构先做场景可行性及原稿矛盾检查；三人以上、进出门、跨台阶、抓握/交物/指认或相邻镜头改变状态时，读取[防穿帮流程与反例经验](references/continuity-workflow.md)。内部建立人物清单、空间关系与逐镜起末状态，再安排机位；单镜与局部修改只核对相关依赖，不强制增加全景或交付状态表。
- 涉及多素材分工、走到目标再操作、暗场或延迟出场时，读取[素材冲突、到达切点与暗场揭示](references/reference-state-gates.md)。核对真实首帧与时长，按到达或接触的完成条件切镜；分别锁定真实在场、画内可见和揭示触发，并用实际可见范围定义暗场。不把相反的图片信息仅靠文字视为已经修正。
- 保留@角色的年龄、服饰、身体状态、持物、伤情和比例。仅写当前画面需要的信息，不把角色设定全文塞进每镜。
- 遇到体型差明显的战斗，主动读取[体型差战斗：尺度与重量](references/scale-weight-combat.md)，按已定资产先建立大小参照，再以接触、介质响应、受力位移和余波表现重量。将方法用于相关镜头，不把全部手段机械叠加到每一镜，也不改变已锁定的体型、胜负、场景和拍法。
- 内部按固定八方位核对入口、通路、建筑、光源、人物与机位，再推算屏幕投影。正文人物相对位置用参照人物自身前后左右，场景朝向及移动写“N方位”等完整表达；换机位不改变世界坐标。
- 每个镜头自动按[场景可见范围与变化继承](references/scene-visibility-state.md)核对允许背景、明确禁入区域及当前场景状态，覆盖起幅、运动途中和落幅；墙面损伤、门窗、灯光及陈设变化发生后，更新所有后续受影响镜头和续接段落，画外不重置。内部逐镜检查，正文只写当前必要的背景与状态，不堆叠禁入清单。
- 生成或重构构图时读取[故事构图与可见性检查](references/composition-story.md)。先锁定观众必须读出的关系，再安排人物、摄影机、取景边界、焦点和遮挡；区分布置空间用的参考视角与真正拍摄机位，不把更换视角写成人物换位。
- 涉及移动时写清起点、经过处、终点、距离变化、前中远景层次和焦点目标；只用维持连续性所需的精度。
- 相邻镜头延续上一镜的动作末态、相对位置、视线和受光面。对话与打斗保持轴线同侧，必要跨轴须有可读过渡。
- 持物与交互按[防穿帮流程](references/continuity-workflow.md)核对实际结构、可见握法及画外姿态继承；先验证世界中的朝向和前后关系，再判断屏幕排列，不把侧拍的横向投影直接判为并排站立。
- 核对固定人数、人物所在平面、出入口、退步空间、门扇运动及最终开合状态。未入画的人物仍保留其位置与人数；补中景不能把门槛平台换成台阶下，镜头变化也不能重置抓握或持物状态。

### 第三步：为每镜安排可实现的摄影

- 涉及第一人称POV、指认或多人同时动作时，读取[防穿帮流程](references/continuity-workflow.md)的可见范围与动作容量规则；逐镜重算视角主人、可见人物和身体部位，将说话、注视、手势目标分开。决定后续空间的走位不能仅藏在失焦背景里。

- 按使用者说明的表达目标、保留项与取舍编排摄影；读取[镜头与剪辑选择库](references/camera-library.md)，将拍法转成具体可见运动。未指定运镜时须已完成意图问答后的3方案选择，不能只在内部选好便出稿；其他焦段、色温等技术细节自行落实，不把每项参数都变成必答题。
- 每镜写明设备或虚拟摄影机、焦段/等效焦段、景别、机位角度、构图重心与焦点。
- 有机位图、正面武器特写或多人贴近时，按[构图中的机位可执行性检查](references/composition-story.md)明确摄影机相对谁、位于哪处可用空间、朝谁拍；区分人物正面与道具展示面，重算反向机位的背景，并验证近大远小来自真实距离而非物件变大。只用必要的可见描述，不把整张空间检查表塞入正文。
- 用摄影机的具体起点、移动路径和结束构图描述运镜；固定镜头不强加运动。相同设备可简写，但不要省去每镜焦段。
- 每次运动或切镜都对应具体动机：新的信息、目光转移、人物行动、关系变化或情绪转折。安排何时靠近、何时停住、何时揭示与何时让反应留在画面里；构图、表演与声音共同引导注意，不以持续运动替代叙事。
- 生僻术语采用“术语＋可见画面解释”，写清主体、起始构图、摄影机路径/转向、速度变化、焦点与结束构图。区分机位移动、变焦、焦点转移和剪辑切换；不将参考库中所有选项都写进同一段。
- 依据选择库中的来源标记区分“官方提到的术语”与“自行编写的描述性方案”。不能宣称全部术语均已实测、SD2.5一定执行成功或不同入口的能力完全相同；能力来源见[检索依据](references/camera-sources.md)。
- 根据画面容量拆分动作。面部近景不同时承载完整脚步、宏大群像和远景细节；极近的接触镜头不要求兼顾全脸和全身。
- 将关键条件分为“状态持续”与“本镜必须看清”。对必须看清的伤口、抓握、门缝或指认对象，写明由哪镜呈现、位于何处、需要怎样的清晰度及如何避开遮挡；不能用背景虚化或一句“始终保留”替代可见证据。用户要求画外隐藏时保持隐藏，不擅自增加入画人物。
- 安排连续近景、特写与正反打时，读取[特写密度与中景过渡](references/shot-transitions.md)。对话转为起身、转身、靠近或离开时，优先用能容纳行动的主体中景承接，保持主体清晰、其他人物与背景柔焦，并保留可辨认的空间锚点。按信息、情绪与动作判断切点，不按固定镜数插镜，也不把“虚影”写成重影或人物消失。
- 用户要求一镜到底、把多镜稿改成长镜或审核长镜时，读取[一镜到底与旁听人物表演](references/continuous-take-performance.md)，准确限定连续段起止：用户明确的前置镜头和切点保留，切入后才一镜到底；以一个镜号组织可走通的连续路线，提前容纳手部与地面动作，再交接表情重点；正文直接描述摄影机连续运镜与构图变化，不用C1、C2、K1等机位序列，不插入硬切或跳位。现场画外对白可用于守住即时反应，但不覆盖已锁定的口型展示；用户要求分镜时才安排剪辑。涉及绕背换边或结尾复合运镜时，核对到位后的主体交接、动作入框及后撤/升高各自完成条件，不将换边自动判为人物换位。

### 第四步：写动作、表演和特效

- 动作按支撑、重心、发力、接触、受力反应与收势推进。保持左右手、支撑脚、武器、接触位置和距离明确。
- 一次攻击只发生一次；动作跨镜时承接原动作，不重新蓄力与重复命中。让衣料、地面、尘土与身体惯性响应受力。
- 伤后伸手、抹血或触胸时，按[状态流程与大厅反例](references/continuity-workflow.md)分别核对持物、手部血迹和清洁状态；空手不等于干净，不为所有项目自动加血或清洁动作。
- 抓握、松手、交物和指认先确定发起者、左右手、对象及触发顺序，再设计能读清关系的构图。关键动作优先在同镜完成或以明确末态匹配切换；指认易混淆时让手与目标同框，或用有空间依据的匹配视线衔接，保留用户明确要求隐藏的信息。
- 用具体目光、呼吸、肩颈、下颌和短暂表情变化表现情绪。将自然、严厉、奸笑、害怕等要求落实为可见动作，保持眼球与注视方向正常。
- 在可改范围内主动增补有因果的微动作、反应、停顿、环境互动与视觉呼应，让情绪发生变化；这些是导演补充，不冒充原稿内容。已经锁定的动作、信息隐藏与结果仍保留，不能靠新增人物、反转或特效强造刺激。
- 群像使用错开的行走、停顿、反应与遮挡；观众需虚化时维持低细节，不挤入清晰单人脸。
- 多人画面按[旁听表演规则](references/continuous-take-performance.md)为画内其他人物安排有因果且主次分明的目光、呼吸、姿态或动作停止，避免僵站与同步表演；反应只依据当时可知信息，不提前知情，不强迫柔焦人物清晰或画外人物入画，不为填满画面新增走位和台词。
- 凡本次编写、审核或修改的内容涉及特效，自动读取并应用[特效来源、阶段与跨镜连续性](references/effects-continuity.md)，无需用户另行提醒。仅在用户要求或剧情已有依据时加入特效，将抽象效果落实为“来源→可见形态→传播/覆盖→作用→末态”，区分主体局部、场景范围与满屏转场，按动作先后安排必要可见性和受力。局部去光只改指定对象及必要溢光，不取消同色道具、正常反射或其他既定效果；方案改换时清除旧阶段、音效及全局尾注中的冲突要求。

遇到打斗、门扇方向、载具飞行、范围结界、绘阵或复杂群像时，读取[空间与动作指南](references/continuity-guide.md)。

### 第五步：选择美术和声音

- 继承当前画风、时间天气、主光方向、色彩关系和材质；不要用全局更电影感重置已锁定的场景。
- 读取[风格规范](references/style-profiles.md)，按需选择真人电影、三渲二水墨或萌宠真实比例。三渲二采用虚拟摄影机和等效焦段，不混写成真人实拍皮肤；在提示词正文中覆盖造型比例、轮廓线条、明暗分区、边缘处理、高光形状、材质、光影、空间、运镜九项，可紧凑合并，但不要只保留风格标签。
- 为对白、脚步、衣料、武器、风、火与环境声指定可理解的来源；声画同步，保留同一空间的声场与混响。
- 分开描述角色音色身份、表演语气与声音处理；神力或威压优先用适量共鸣、混响和环境音效表达，只有剧情明确要求才更换声线。未实际听辨音轨时，不把用户反馈或文字推测说成已听出的结论。
- 口型仅对应实际发声的原句；译文不另读。可见说话者自然对口型，其他角色保持倾听；OS内心独白及VO画外音不强制绑定可见角色开口，不把内心声改成喊话。仅有动物角色时按物种发声。
- 色卡与比例图只在用户要求、制作稿或相应工作流需要时提供，不为普通提示词附加整套无关资产。

### 第六步：按意图审核后交付

出稿或修改完成后，执行[出稿完成条件与修改回归检查](references/continuity-workflow.md)中的五项核对，依据当前最终正文逐项检查动作阶段、相邻起末态、机位可行性、镜头容量和公共约束。局部修改先确定受影响镜头及依赖，再通读全稿寻找旧状态；不能用“已保持一致”代替具体核对，也不能把尚有明确矛盾的稿件交付为已检查完成。纯审核只报告结论，不自动改稿。

审片归因按[意图驱动审核](references/intent-review.md)区分文字明确矛盾、设计漏洞、模型未执行明确要求及证据不足；成片事实、原文要求和原因推测分别核对，不把正确的原文顺序说成写反了。

人物关系、可见范围、动作起末态和触发顺序已明确且没有新增证据时，按该参考中的停止条件结束审核，不为每轮凑问题或继续堆限制；剩余执行风险不能当作新的文字错误。

读取[意图驱动审核](references/intent-review.md)，先判断现有镜头能否实现制作人的目标，再核对以下项目。用户要求审核时说明条件、阻碍与修正；用户只要提示词时内部完成检查并输出所需正文，不强加冗长审片报告。

1. 用户必需的剧情、台词、人物、物件和保留项是否完整；导演补充是否有因果，是否无依据改变了核心故事或超出局部修改范围。
2. 人物身份、服饰、比例、持物、伤情、角色@标记是否稳定。
3. 内部世界坐标是否固定；正文人物相对位置是否按参照人物自身朝向写前后左右，场景朝向和移动的N/NE等字母后是否有“方位/方向”；俯视图八向罗盘是否齐全且跨镜不旋转，屏幕投影、距离、视线、轴线与光源是否连续。
4. 景别能否容纳指定内容；动作起末态、受力和接触次数是否匹配。
5. 表情、眼球、口型、手部、宠物关节与群像运动是否自然。
6. 镜号是否正确；是否误加秒数、字幕、BGM或与当前画风冲突的描述；是否仍自动写出了用户要求省略的画幅或帧率表述；真人成稿是否在末尾合并一次适用的八项质感与连续性约束，其他含运动片段是否追加一次摄影尾注，且未重复、未覆盖具体拍法与剧情特效。
7. 是否按[任务分流与阶段放行](references/question-flow.md)进入了正确阶段：新创作是否完成所需问答；纯审核是否先报告确定问题；局部修改是否沿用当前设定并保持范围。是否区分明确意图与推断，保留信息揭示顺序，不把有意隐瞒或非常规拍法直接判错。
8. 方案是否超出了剧本复述：是否有明确的视觉重心、观众关注的问题、情绪变化、必要的反应与兑现；画面层次和运动动机是否具体；是否把吸引力误等同于更多运镜、快切、特效或夸张表情。
9. 连续特写是否重复相同信息、切掉行动准备或使空间关系丢失；该转为中景时是否给主体动作和去向留出空间，焦点是否跟随，是否在动作尚未读清时无必要地切回特写。已锁定的长镜、固定景别和局部修改范围仍优先。
10. 按[防穿帮流程](references/continuity-workflow.md)逐对核查“上一镜结束→下一镜开始”：位置、手部接触、视线/指向对象、人数、道具和门扇状态是否有依据地延续。按[构图检查](references/composition-story.md)核对首态、关键动作、末态：要求看清的细节是否实际可见，摄影机运动是否导致遮挡，最后一镜是否兑现结束状态。不把文本自洽说成视频已验证无误。
11. 当前创作分支需要运镜选择时，是否按权威流程完成了3方案适配检查和用户选择；已指定运动及不涉及运镜的审核、局部修改不重弹菜单。仅有景别、角度或一镜到底要求不代表已指定运动；不把转焦、变焦和剪辑假称为机位移动。
12. 未明确要求逐镜秒数时，是否保持“镜号1：……”且没有擅加逐镜秒数、时间码或主动发起秒数选择；用户明确要求逐镜标注时，按对白、动作和运镜分配，若指定总长须核对各镜相加一致。默认不标秒不影响意图提问及必要的运镜3选1。
13. 涉及角色知情差异时，是否按[叙事前提检查](references/narrative-conditions.md)核对察觉触发、真实视听条件、禁同框组合及行动时机；每种候选和最终稿均须通过。是否只把人物移出画框，却仍让故事中的观察者有无解释的直视或听见机会；是否擅自改变先推谁、谁先进入等锁定顺序。区分文本设计缺陷与成片执行偏差，不在缺少原提示词时猜定原因。
14. 体型差战斗是否按[尺度与重量检查](references/scale-weight-combat.md)给出可读参照，保持人物和环境比例；落脚、命中、尘屑与位移是否有先后依据；反击高度和距离是否实际可达；快切后是否仍能读清接触与受力。尊重单人、固定景别、无破坏等限制，不强加巨人化、飞退、震屏或地面开裂。
15. 多素材是否各有职责且已检查实际冲突；连续交互是否在到达、接触等条件完成后切镜；隐藏人物是否始终在场而非被人数限制排除；暗部是否真的隐藏目标直到既定触发。按[素材与揭示检查](references/reference-state-gates.md)核对起幅、运动中途及末态，分别说明文本可执行性、成片事实与原因推测，不提前保证生成无误。
16. 涉及特效时，是否按[特效检查](references/effects-continuity.md)核对宿主、形态、触发、传播、覆盖、受力、跨镜末态与声画顺序；区分局部发光、正常反光、场景照明和屏幕覆盖，核对去光范围与满屏转场结尾。道具分离后来源仍在正确部件，瞬移阶段与时间静止例外一致；更换效果或取消声音后清理旧要求。未要求的特效、配乐、参数及其他项目固定颜色不自动加入。
17. 是否逐镜通过[场景可见范围与变化检查](references/scene-visibility-state.md)：实际机位与运镜全过程没有带出明确禁入的背景，场景变化已按因果传递到所有后续相关画面，旧素材没有把损伤、门窗、灯光或陈设重置；背景柔焦不代替画外，反打不移动墙面，不把场景一致误写成所有镜头同一背景。
18. 站位图是否只用于确需中景/全景交代空间的段落，纯近景/特写是否省图；白模是否仅因实际特效而考虑且生成前已有用户同意，未因人数、穿帮或旧白模自动升级；是否避免默认追加阶段图、关键构图和起落幅。
19. 有图时是否核对当前正文、数据、实际图片、视觉检查及交付引用；段首是否一次写清必要站位/锚点/映射，逐镜是否只写变化。无图时是否清理悬空引用并继续内部空间检查；长镜仍不画摄影机轨迹、正文不用途经机位序列。维护绘图规则时运行[工具用例](scripts/test_blocking.py)和相关[制作行为试用](references/behavior-regression.md)，分开记录工具、AI行为与视频验收范围。

20. 一镜到底是否按[长镜核对](references/continuous-take-performance.md)连续交代摄影机路径、景别和焦点，关键动作是否先获得取景空间，是否为了等摄影机无依据冻结人物。多人画内旁听反应是否克制、不同步且符合知情状态；画外对白与反应触发、说话者和口型是否对应，是否把可选拍法或固定焦段推广为通用要求。

## 4. 控制定向修改的范围

- “只改X”时只修改X及其不可避免的依赖。人物描述替换时，不顺便改台词、机位、焦段或剧情。
- 修改依赖按[出稿回归检查](references/continuity-workflow.md)落实：追踪前后镜、画外姿态、重复出现的同一状态、声音触发与公共结尾，清除被最新要求替代的旧描述；全文检查不扩大修改权限，未受影响的原文保持。
- 每次修改已有提示词后，默认交付当前片段或稿件的最新完整可复制正文，不只给替换段，也不用“其余不变”省略执行所需内容；修改范围仍只限指定项及必要依赖，重发全文不等于获准重写全文。只有本次明确要求“只给修改段/单句/差异”时才局部交付；当前任务本来就只有一个镜号时，不扩写整集。
- 保留必须保留的物件、背景锚点和具体设计。指定镜号、补镜与局部修改保留原定位；整段导演重构可重排、增减非锁定镜头并连续编号，不能以优化为由删除核心情节或必须保留项。
- 最终提示词用具体的人物、动作和空间描述表达目标，不写“参考原视频”“参考原图”等泛指措辞。
- 不用“同上”“其余不变”替代完整稿里执行所需的内容；单独的修改指令按用户范围交付即可。

## 5. 交付格式

- 按[权威流程](references/question-flow.md)确定本轮应交问题、运镜选择、审核结论还是成稿，不跨阶段抢先出稿，也不让不适用的问卷阻碍已可完成的工作。正式稿默认给一个可复制、无空白间隔行的文本代码块，依次写整体设定、必要的人物/空间锁定、镜号段落和声音连续性。镜号默认用“镜号1：……”；只有用户明确要求逐镜标秒时才可用“镜号1（4秒）：……”。结构复杂时才加小标签；不用分镜表代替正文，除非用户指定表格。
- 纯审核先给有依据的问题与成立条件；审核并改写按范围再给必要的情绪/特写建议及修改稿。只要提示词时内部完成检查后给正文，不再主动询问是否逐镜标秒或请求重复确认。必要推断明确标注，不添加评分、营销语或反复询问是否继续。
- 明显的导演重构可用1–3句说明改变了哪种观看体验、保留了什么及主要取舍；用户只要提示词时将设计落实在正文，不强加多方案、理论课或长篇创作阐述。不得用“更精美、更吸引人”代替具体画面。
- 单镜头只保留本镜所需设定，完整稿则实际写出所有执行所需的锁定信息。不要把单镜需求扩成一整段新剧情。
- 查看[格式与短例](references/prompt-patterns.md)，按完整稿、单镜头、定向修改或图生视频选择写法。
- 以文字提示词为主，仅为确需中景/全景交代空间的段落按[配图门槛](references/blocking-camera-diagrams.md)交付必要站位图；白模有实际特效且用户已同意才生成。站位约束在该段开头集中一次说明，镜号中只写可见动作与变化，不附默认整套配图。用户本次只要文字或不要图时遵从；参考图只辅助空间，不声称视频已生成或保证零穿帮。

## Modification Log

目录：`Modification Log/`；查看[修改日志](<Modification Log/modification-log.md>)。

- 每次修改本技能的规则、参考资料、脚本、资源或界面元数据时，先读取修改日志，完成后在文件末尾追加本次修改的内容、作用及涉及文件，与技能更新一起保存；保留已有记录。
- 日期按北京时间（Asia/Shanghai）填写，统一使用 `YYYY-MM-DD am` 或 `YYYY-MM-DD pm`：中午前为 am，中午起为 pm；不写具体时、分、秒。同日多次修改分别追加，用标题区分。
- 一次更新涉及多个文件时合并为一条记录；仅记录实际完成的修改。回填历史时依据可核实的版本记录，不编造日期或修改效果。
- 日常生成、审核或修改视频提示词不属于技能文件更新，不追加日志，也不在提示词正文中输出日志。
