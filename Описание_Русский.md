# Режиссёр видеопромптов

Преобразует сюжетные эпизоды, визуальные идеи и замечания в покадровые промпты для генерации видео с помощью ИИ. Предназначен для работы с Seedance / SD и похожими инструментами. Основное внимание — постановке кадра, понятным пространственным связям, непрерывности действий и типичным визуальным ошибкам.

## Возможности

- **От сюжета к раскадровке:** Прорабатывает композицию, мизансцену и развитие эмоций, сохраняя основной сюжет, отношения персонажей, заданные реплики и итог событий.
- **Уточнение замысла и выбор движения камеры:** Для нового эпизода задаёт 1–3 ключевых вопроса. Если движение камеры не задано, после ответов предлагает три подходящих варианта.
- **Камера и звук:** По необходимости описывает крупность плана, фокусное расстояние, положение и движение камеры, свет, актёрскую игру, диалоги и звуки окружения.
- **Проверка непрерывности:** Проверяет ось съёмки, направления взглядов, осведомлённость персонажей, физические контакты, принадлежность реквизита, состояние дверей и окон, согласованность освещения.
- **Дополнительные кадры и точечные правки:** Учитывает подтверждённые настройки и ограничивает изменения запрошенным участком.
- **Схемы по необходимости:** Добавляет схемы расположения персонажей и камер, когда средний или общий план требует пояснения пространства. Для крупных планов схемы можно опустить. Перед созданием блокинга VFX в виде белых макетов запрашивает согласие.

## Настройки по умолчанию

- Промпты составляются на китайском языке; язык заданных реплик сохраняется. Без указания пользователя реплики не переписываются, не добавляются и не переводятся автоматически.
- Кадры обозначаются как `镜号1`, `镜号2` и далее. Длительность каждого кадра указывается только по прямому запросу; вопрос о добавлении секунд заранее не задаётся.
- По умолчанию — без фоновой музыки, добавленных субтитров и водяных знаков. Текущие прямые указания пользователя имеют приоритет.
- Сохраняются имена ресурсов персонажей, установленные параметры проекта и ограничения точечных правок.
- Проверка помогает снизить вероятность типичных ошибок, но не гарантирует безупречную генерацию с первой попытки.

## Скачивание и установка

1. Откройте раздел [Releases](https://github.com/IU000-78/write-videoZZZ/releases) этого репозитория.
2. В списке Assets скачайте прикреплённый автором файл `write-video-prompts-plugin.zip`.
3. В среде ChatGPT / Codex с поддержкой импорта ZIP-плагинов загрузите этот архив через интерфейс импорта плагинов.
4. Выберите «视频提示词导演» и отправьте сюжет, исходные материалы или промпты для редактирования.

Расположение элементов установки зависит от клиента. Плагину нужна ИИ-среда с поддержкой навыков. GitHub хранит и распространяет файлы, но не выполняет генерацию видео.

## Примеры запросов

**Создать раскадровку**

> Используй Режиссёра видеопромптов, чтобы преобразовать следующий сюжет в покадровые промпты для Seedance. Сначала уточни творческий замысел. Если движение камеры не задано, предложи три варианта. Сохрани реплики и по умолчанию не указывай длительность кадров.

**Проверить непрерывность**

> Проверь приведённые ниже промпты: пространственные связи, ось съёмки, осведомлённость персонажей и непрерывность действий. Сначала укажи явные ошибки, затем предложи исправления, не меняя основной сюжет.

**Внести точечную правку**

> Измени только кадр 3: персонаж сначала поворачивается, затем говорит; двустворчатые двери на заднем плане полностью закрыты. Остальные настройки, номера кадров и реплики оставь без изменений.

По умолчанию навык создаёт видеопромпты на китайском языке. Английский и русский README — переводы описания проекта; они не означают полной многоязычной адаптации навыка.

## Структура репозитория

- `plugin.json` — конфигурация плагина.
- `skills/write-video-prompts/SKILL.md` — основные инструкции навыка.
- `skills/write-video-prompts/references/` — материалы по режиссуре, камере, непрерывности и проверке.
- `skills/write-video-prompts/scripts/` — вспомогательные скрипты.
- `skills/write-video-prompts/assets/` — значки и шаблоны.
